# Menambah Data dengan INSERT

Sampai sekarang kita hanya **membaca** data dengan `SELECT`. Mulai unit ini, kita belajar **mengubah** data — dimulai dengan `INSERT`, perintah untuk menambahkan baris baru.

:::note
Semua perintah `INSERT`/`UPDATE`/`DELETE` yang kamu coba di playground ini hanya mengubah salinan database yang berjalan **di browser-mu sendiri**. Klik tombol **Reset** kapan saja untuk mengembalikan data ke kondisi semula.
:::

## INSERT Dasar

```sql
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit)
VALUES (13, 'Bumi', 'Tere Liye', 'Fiksi', 70000, 5, 2014);
```

- **`INSERT INTO buku`** — tabel tujuan
- **`(id, judul, penulis, kategori, harga, stok, tahun_terbit)`** — daftar kolom yang akan diisi, dalam urutan tertentu
- **`VALUES (...)`** — nilai yang sesuai, dalam urutan yang **sama persis** dengan daftar kolom

Setelah dijalankan, coba `SELECT * FROM buku WHERE id = 13;` untuk melihat baris barunya.

## Kenapa Daftar Kolom Penting

```sql
-- Berisiko: mengandalkan urutan kolom asli tabel, mudah salah kalau skema berubah
INSERT INTO buku VALUES (14, 'Rentang Waktu', 'Fiksi', 'Fiksi', 62000, 8, 2010);
```

:::warning
`INSERT` tanpa daftar kolom eksplisit mengasumsikan kamu tahu **persis** urutan kolom asli tabel — kalau salah urutan (seperti contoh di atas: `penulis` dan `kategori` tertukar), data akan masuk ke kolom yang salah **tanpa error**! Selalu tulis daftar kolom secara eksplisit, meski lebih panjang.
:::

## Menambah Banyak Baris Sekaligus

```sql
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit) VALUES
  (13, 'Bumi', 'Tere Liye', 'Fiksi', 70000, 5, 2014),
  (14, 'Bulan', 'Tere Liye', 'Fiksi', 72000, 3, 2015);
```

Satu perintah `INSERT` bisa menambahkan banyak baris dengan memisahkan tiap tanda kurung `(...)` menggunakan koma — jauh lebih efisien daripada menulis `INSERT` berkali-kali.

## INSERT dan Primary Key

Kolom `id` di tabel `buku` adalah `PRIMARY KEY`, artinya nilainya harus **unik**. Mencoba `INSERT` dengan `id` yang sudah ada akan menghasilkan error:

```sql
-- ERROR: id 1 sudah dipakai oleh 'Laskar Pelangi'
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit)
VALUES (1, 'Judul Lain', 'Penulis Lain', 'Fiksi', 50000, 1, 2020);
```

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| INSERT satu baris | `INSERT INTO buku (kolom...) VALUES (nilai...);` |
| INSERT banyak baris | `VALUES (...), (...), (...);` |
| Praktik aman | Selalu tulis daftar kolom eksplisit |
| Batasan Primary Key | Nilai `id` harus unik, tidak boleh duplikat |

Selanjutnya: mengubah data yang sudah ada dengan **UPDATE**.
