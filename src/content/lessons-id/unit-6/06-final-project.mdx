# Final Project: Rancang Database Sendiri

Selamat datang di proyek penutup kursus Belajar SQL! Playground di lesson ini **benar-benar kosong** — kamu akan merancang skema, mengisi data, dan menganalisisnya sendiri dari nol, menggabungkan **semua** yang sudah kamu pelajari dari Unit 0 sampai Unit 6.

## Skenario: Sistem Toko Kelontong Sekolah

Kamu diminta merancang database sederhana untuk toko kelontong sekolah, yang mencatat **produk** dan **transaksi penjualan**.

## Langkah 1: Rancang Skema

```sql
CREATE TABLE produk (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL,
  harga INTEGER NOT NULL CHECK (harga >= 0),
  stok INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE transaksi (
  id INTEGER PRIMARY KEY,
  produk_id INTEGER NOT NULL REFERENCES produk(id),
  jumlah INTEGER NOT NULL CHECK (jumlah > 0),
  tanggal TEXT NOT NULL
);
```

Perhatikan bagaimana skema ini menerapkan pelajaran dari seluruh unit: `PRIMARY KEY` dan `FOREIGN KEY` (Unit 4), `NOT NULL`/`CHECK`/`DEFAULT` (Unit 6).

## Langkah 2: Isi Data Awal

```sql
INSERT INTO produk (id, nama, harga, stok) VALUES
  (1, 'Pensil', 2500, 100),
  (2, 'Buku Tulis', 5000, 50),
  (3, 'Penghapus', 1500, 80),
  (4, 'Penggaris', 3000, 40);

INSERT INTO transaksi (id, produk_id, jumlah, tanggal) VALUES
  (1, 1, 5, '2026-06-01'),
  (2, 2, 2, '2026-06-01'),
  (3, 1, 3, '2026-06-02'),
  (4, 3, 10, '2026-06-02'),
  (5, 2, 1, '2026-06-03');
```

## Langkah 3: Analisis dengan JOIN, Agregasi, dan Subquery

```sql
-- Total pendapatan per produk (JOIN + agregasi dari Unit 3 & 4)
SELECT produk.nama, SUM(produk.harga * transaksi.jumlah) AS total_pendapatan
FROM transaksi
INNER JOIN produk ON transaksi.produk_id = produk.id
GROUP BY produk.nama
ORDER BY total_pendapatan DESC;
```

```sql
-- Produk yang belum pernah terjual (LEFT JOIN dari Unit 4)
SELECT produk.nama
FROM produk
LEFT JOIN transaksi ON produk.id = transaksi.produk_id
WHERE transaksi.id IS NULL;
```
