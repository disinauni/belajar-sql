# Membuat Tabel dengan CREATE TABLE

Sejauh ini kita selalu bekerja dengan tabel yang **sudah disiapkan** untuk kita. Sekarang saatnya belajar sisi lain SQL: merancang tabel sendiri dari nol. Playground di lesson ini **kosong** — tidak ada tabel apapun sampai kamu membuatnya sendiri!

## CREATE TABLE Dasar

```sql
CREATE TABLE siswa (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL,
  nilai INTEGER
);
```

- **`CREATE TABLE siswa`** — nama tabel baru
- Setiap baris di dalam kurung mendefinisikan satu kolom: **nama kolom**, lalu **tipe data**-nya
- `PRIMARY KEY` dan `NOT NULL` adalah *constraint* (aturan) — dibahas lebih detail di lesson berikutnya

Setelah dibuat, tabel `siswa` masih **kosong** — `CREATE TABLE` hanya mendefinisikan struktur, belum mengisi data.

## Tipe Data Dasar SQLite

| Tipe | Untuk Menyimpan | Contoh |
|------|-------------------|--------|
| `INTEGER` | Bilangan bulat | `17`, `0`, `-5` |
| `REAL` | Bilangan desimal | `3.14`, `72500.5` |
| `TEXT` | Teks/string | `'Budi'`, `'Fiksi'` |

```sql
CREATE TABLE produk (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL,
  harga REAL NOT NULL,
  stok INTEGER
);
```

:::note
SQLite sebenarnya memakai sistem tipe yang lebih fleksibel ("type affinity") dibanding RDBMS lain seperti PostgreSQL/MySQL — ia tidak selalu memaksakan tipe data seketat itu. Tapi tetap deklarasikan tipe data dengan benar, karena RDBMS lain jauh lebih ketat, dan ini kebiasaan baik yang membuat skemamu jelas dibaca siapapun.
:::

## Mengisi Tabel Baru dengan INSERT

Setelah struktur tabel ada, kamu bisa langsung `INSERT` seperti biasa:

```sql
CREATE TABLE siswa (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL,
  nilai INTEGER
);

INSERT INTO siswa (id, nama, nilai) VALUES
  (1, 'Dewi', 88),
  (2, 'Farhan', 92);

SELECT * FROM siswa;
```

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Buat tabel | `CREATE TABLE nama (kolom tipe, ...);` |
| Tipe data | `INTEGER`, `REAL`, `TEXT` |
| Tabel baru | Selalu kosong sampai di-`INSERT` |
| DDL vs DML | `CREATE TABLE` = DDL (struktur), `INSERT`/`UPDATE`/`DELETE` = DML (data) |

Selanjutnya: memperketat aturan data dengan **constraint** — `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `DEFAULT`, dan `CHECK`.
