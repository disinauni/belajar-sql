# Mengubah Data dengan UPDATE

`UPDATE` mengubah nilai kolom pada baris yang **sudah ada** di tabel — berbeda dengan `INSERT` yang menambah baris baru.

## UPDATE Dasar

```sql
UPDATE buku
SET stok = 15
WHERE id = 1;
```

- **`UPDATE buku`** — tabel yang akan diubah
- **`SET stok = 15`** — kolom mana yang diubah, dan nilai barunya
- **`WHERE id = 1`** — baris mana saja yang terkena perubahan ini

Coba `SELECT * FROM buku WHERE id = 1;` setelah menjalankan `UPDATE` di atas untuk melihat perubahannya.

## Mengubah Banyak Kolom Sekaligus

```sql
UPDATE buku
SET harga = 75000, stok = 20
WHERE id = 1;
```

Pisahkan tiap `kolom = nilai` dengan koma di dalam satu `SET`.

## BAHAYA: UPDATE Tanpa WHERE

```sql
-- BAHAYA! Ini mengubah stok SEMUA baris di tabel jadi 0, bukan cuma satu buku
UPDATE buku SET stok = 0;
```

:::warning
`UPDATE` **tanpa `WHERE`** mengubah **SEMUA baris** di tabel, bukan cuma satu. Ini adalah salah satu kesalahan paling merusak dalam SQL — di dunia nyata (bukan playground ini), ini bisa berarti kehilangan data produksi secara permanen. Selalu double-check klausa `WHERE` sebelum menjalankan `UPDATE`, terutama di database sungguhan.
:::

:::tip
Kebiasaan aman: sebelum menjalankan `UPDATE`, jalankan dulu `SELECT` dengan `WHERE` yang sama untuk melihat **baris mana saja** yang akan terkena dampak. Kalau hasil `SELECT`-nya sesuai harapan, baru ganti `SELECT *` menjadi `UPDATE ... SET ...`.
:::

## UPDATE Berdasarkan Kondisi yang Mengenai Banyak Baris

```sql
-- Naikkan harga 10% untuk semua buku kategori Fiksi
UPDATE buku
SET harga = harga * 1.1
WHERE kategori = 'Fiksi';
```

Perhatikan `harga = harga * 1.1` — nilai baru bisa dihitung dari nilai **lama** kolom yang sama, bukan cuma nilai tetap.

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| UPDATE dasar | `UPDATE buku SET stok = 15 WHERE id = 1;` |
| Banyak kolom | `SET harga = 75000, stok = 20` |
| Hitung dari nilai lama | `SET harga = harga * 1.1` |
| BAHAYA | `UPDATE` tanpa `WHERE` mengubah SEMUA baris |

Selanjutnya: menghapus baris dengan **DELETE** — sama pentingnya untuk berhati-hati dengan `WHERE`.
