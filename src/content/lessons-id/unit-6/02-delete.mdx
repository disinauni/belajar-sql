# Menghapus Data dengan DELETE

`DELETE` menghapus baris dari tabel — perintah DML terakhir setelah `INSERT` dan `UPDATE`.

## DELETE Dasar

```sql
DELETE FROM buku WHERE id = 6;
```

Baris dengan `id = 6` akan hilang permanen dari database yang sedang berjalan. Coba `SELECT * FROM buku;` sesudahnya — baris itu sudah tidak ada lagi.

## DELETE Berdasarkan Kondisi

```sql
-- Hapus semua buku dengan stok 0
DELETE FROM buku WHERE stok = 0;
```

```sql
-- Hapus buku kategori Keuangan yang harganya di bawah 100000
DELETE FROM buku WHERE kategori = 'Keuangan' AND harga < 100000;
```

Semua teknik `WHERE` dari Unit 1-2 (operator perbandingan, `AND`/`OR`, `IN`, `BETWEEN`, dst) berlaku sama persis untuk `DELETE`.

## BAHAYA: DELETE Tanpa WHERE

```sql
-- BAHAYA! Ini menghapus SEMUA baris di tabel buku, tabelnya sendiri masih ada tapi kosong
DELETE FROM buku;
```

:::warning
Sama seperti `UPDATE`, `DELETE` **tanpa `WHERE`** akan menghapus **SEMUA baris** di tabel. Ini salah satu perintah paling berbahaya dalam SQL — selalu periksa ulang `WHERE`-mu, dan di database sungguhan, pertimbangkan menjalankan `SELECT` dengan `WHERE` yang sama dulu untuk memastikan baris yang akan terhapus benar-benar yang kamu maksud.
:::

## DELETE vs DROP TABLE

Penting untuk tidak tertukar antara dua perintah ini:

| Perintah | Efek |
|----------|------|
| `DELETE FROM buku;` | Menghapus **semua baris**, tabel `buku` (struktur/skemanya) tetap ada, kosong |
| `DROP TABLE buku;` | Menghapus **tabel itu sendiri** sepenuhnya — struktur dan semua datanya hilang |

Kita akan membahas `DROP TABLE` lebih detail di lesson **ALTER TABLE & DROP TABLE**.

:::tip
Setelah `DELETE FROM buku;`, kamu masih bisa `INSERT` data baru ke tabel `buku` karena strukturnya masih ada. Setelah `DROP TABLE buku;`, kamu harus `CREATE TABLE buku (...)` lagi dari nol sebelum bisa memakainya.
:::

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| DELETE dasar | `DELETE FROM buku WHERE id = 6;` |
| DELETE dengan kondisi | Semua teknik `WHERE` dari unit sebelumnya berlaku |
| BAHAYA | `DELETE` tanpa `WHERE` menghapus SEMUA baris |
| Beda dengan DROP TABLE | `DELETE` hapus baris, `DROP TABLE` hapus tabel |

Kamu sudah menguasai `INSERT`, `UPDATE`, `DELETE` — tiga perintah DML utama! Selanjutnya kita masuk ke DDL: merancang tabel sendiri dari nol dengan **CREATE TABLE**.
