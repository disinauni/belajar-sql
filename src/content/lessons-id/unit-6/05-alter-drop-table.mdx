# ALTER TABLE & DROP TABLE

Kadang tabel yang sudah ada perlu diubah strukturnya — menambah kolom baru, mengganti nama, atau (dalam kasus ekstrem) dihapus sepenuhnya. `ALTER TABLE` dan `DROP TABLE` adalah perintah DDL untuk ini.

## Menambah Kolom dengan ALTER TABLE ADD COLUMN

```sql
CREATE TABLE buku (
  id INTEGER PRIMARY KEY,
  judul TEXT NOT NULL
);

ALTER TABLE buku ADD COLUMN rating REAL;

SELECT * FROM buku;
```

Tabel yang sudah punya data tetap aman — baris yang sudah ada akan mendapat nilai `NULL` untuk kolom baru itu, kecuali kamu tambahkan `DEFAULT`:

```sql
ALTER TABLE buku ADD COLUMN stok INTEGER DEFAULT 0;
```

## Mengganti Nama Tabel

```sql
ALTER TABLE buku RENAME TO koleksi_buku;
```

## Mengganti Nama Kolom

```sql
ALTER TABLE koleksi_buku RENAME COLUMN judul TO judul_buku;
```

:::note
SQLite historis hanya mendukung operasi `ALTER TABLE` yang terbatas (`ADD COLUMN`, `RENAME TABLE`, `RENAME COLUMN`) dibanding RDBMS lain seperti PostgreSQL yang bisa mengubah tipe data kolom langsung. Untuk perubahan kompleks di SQLite, pola umumnya adalah: buat tabel baru dengan struktur yang diinginkan, salin data, hapus tabel lama, ganti nama tabel baru.
:::

## DROP TABLE — Menghapus Tabel Sepenuhnya

```sql
DROP TABLE koleksi_buku;
```

Setelah ini, tabel `koleksi_buku` **beserta seluruh datanya** hilang total — bukan cuma isinya (seperti `DELETE FROM`), tapi strukturnya juga tidak ada lagi.

:::warning
`DROP TABLE` tidak bisa dibatalkan. Ini adalah perintah paling merusak dalam SQL — bahkan lebih drastis dari `DELETE` atau `UPDATE` tanpa `WHERE`, karena menghapus definisi tabelnya juga. Di database produksi sungguhan, `DROP TABLE` biasanya dibatasi hanya untuk administrator dengan proses persetujuan khusus.
:::

## Ringkasan

| Perintah | Efek |
|----------|------|
| `ALTER TABLE ... ADD COLUMN` | Menambah kolom baru ke tabel yang sudah ada |
| `ALTER TABLE ... RENAME TO` | Mengganti nama tabel |
| `ALTER TABLE ... RENAME COLUMN` | Mengganti nama kolom |
| `DROP TABLE` | Menghapus tabel beserta strukturnya secara permanen |
