# Subquery di SELECT & FROM

Subquery tidak hanya bisa dipakai di `WHERE` — subquery juga bisa muncul di `SELECT` (sebagai kolom tambahan) dan di `FROM` (sebagai "tabel" yang dihasilkan dari query lain).

## Subquery di SELECT — Menampilkan Nilai Pembanding

```sql
SELECT
  judul,
  harga,
  (SELECT AVG(harga) FROM buku) AS rata_rata_semua
FROM buku;
```

Setiap baris hasil sekarang menampilkan harganya sendiri **berdampingan** dengan rata-rata keseluruhan — berguna untuk membandingkan tanpa harus menjalankan dua query terpisah.

```sql
-- Selisih harga tiap buku dari rata-rata keseluruhan
SELECT
  judul,
  harga,
  harga - (SELECT AVG(harga) FROM buku) AS selisih_dari_rata_rata
FROM buku;
```

:::note
Subquery di `SELECT` dijalankan **ulang untuk setiap baris** hasil (secara konsep) — meski untuk subquery non-correlated seperti ini, SQLite cukup pintar untuk menghitungnya sekali saja karena hasilnya selalu sama.
:::

## Subquery di FROM — Tabel Turunan (Derived Table)

Kamu bisa memakai hasil sebuah query sebagai "tabel sementara" untuk di-query lagi:

```sql
SELECT kategori, rata_rata
FROM (
  SELECT kategori, AVG(harga) AS rata_rata
  FROM buku
  GROUP BY kategori
) AS ringkasan_kategori
WHERE rata_rata > 80000;
```

Query di dalam kurung menghasilkan tabel sementara bernama `ringkasan_kategori` (lewat alias), lalu query luar men-`SELECT`/`WHERE` dari tabel sementara itu — persis seperti tabel biasa.

:::tip
Pola ini berguna ketika kamu perlu menyaring berdasarkan hasil `GROUP BY` dengan cara yang lebih fleksibel daripada `HAVING`, atau ketika kamu ingin memproses hasil agregat lebih lanjut (misalnya menghitung agregat dari agregat).
:::

## Kapan Pakai yang Mana?

| Kebutuhan | Taruh Subquery di |
|-----------|---------------------|
| Menyaring baris berdasarkan perbandingan | `WHERE` |
| Menampilkan nilai pembanding sebagai kolom | `SELECT` |
| Memproses hasil query lain sebagai "tabel" | `FROM` |

## Ringkasan

| Lokasi | Kegunaan | Contoh |
|--------|----------|--------|
| `WHERE` | Menyaring baris | `WHERE harga > (SELECT AVG(harga) FROM buku)` |
| `SELECT` | Kolom nilai pembanding | `(SELECT AVG(harga) FROM buku) AS rata_rata` |
| `FROM` | Tabel turunan | `FROM (SELECT ... ) AS alias` |

Selanjutnya: memakai subquery bersama **IN** untuk mencocokkan dengan daftar hasil, bukan cuma satu nilai.
