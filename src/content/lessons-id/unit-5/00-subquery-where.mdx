# Subquery di WHERE

Bayangkan pertanyaan ini: **"buku mana saja yang harganya di atas rata-rata harga SEMUA buku?"**. Kamu butuh dua langkah: (1) hitung rata-rata semua buku, (2) bandingkan tiap buku dengan angka itu. **Subquery** memungkinkan kamu melakukan keduanya dalam **satu** query.

## Subquery Dasar di WHERE

```sql
SELECT judul, harga
FROM buku
WHERE harga > (SELECT AVG(harga) FROM buku);
```

<img src="/images/subquery-nesting.svg" alt="Subquery dievaluasi lebih dulu, hasilnya dipakai query luar" width="100%" />

Bagian `(SELECT AVG(harga) FROM buku)` adalah **subquery** — query lengkap yang ditulis di dalam tanda kurung, menjadi bagian dari kondisi `WHERE` query utama (disebut **query luar**).

## Urutan Evaluasi

SQLite mengevaluasi subquery **lebih dulu**, baru memakai hasilnya untuk mengevaluasi query luar:

1. Jalankan `SELECT AVG(harga) FROM buku` → hasilnya satu angka, misalnya `82916.67`
2. Substitusi angka itu ke query luar: `WHERE harga > 82916.67`
3. Jalankan query luar dengan kondisi yang sudah "diisi" itu

## Subquery vs Menghitung Manual

Tanpa subquery, kamu harus menjalankan dua query terpisah dan menyalin angkanya secara manual:

```sql
-- Langkah 1: cari tahu rata-ratanya (misalnya hasilnya 82916.67)
SELECT AVG(harga) FROM buku;

-- Langkah 2: salin angka itu manual ke query kedua
SELECT judul FROM buku WHERE harga > 82916.67;
```

Subquery menggabungkan kedua langkah ini jadi satu query yang selalu akurat — kalau data berubah, subquery otomatis menghitung ulang, tidak seperti angka yang disalin manual.

## Subquery dengan Operator Lain

Subquery yang menghasilkan **satu nilai** (disebut *scalar subquery*) bisa dipakai dengan operator perbandingan apapun:

```sql
-- Buku termurah (bandingkan dengan hasil MIN dari subquery)
SELECT judul, harga FROM buku WHERE harga = (SELECT MIN(harga) FROM buku);
```

:::warning
Subquery yang dipakai dengan `=`, `>`, `<`, dst harus mengembalikan **tepat satu baris, satu kolom**. Kalau subquery mengembalikan lebih dari satu baris, SQLite akan error. Untuk subquery yang mengembalikan banyak baris, gunakan `IN` (dibahas di lesson berikutnya).
:::

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Subquery di WHERE | `WHERE harga > (SELECT AVG(harga) FROM buku)` |
| Scalar subquery | Subquery yang menghasilkan satu baris, satu kolom |
| Urutan evaluasi | Subquery dulu, baru query luar |

Selanjutnya: menaruh subquery di klausa **SELECT** dan **FROM**, bukan cuma di WHERE.
