# CTE (WITH) & UNION

Dua teknik terakhir di unit ini: **CTE** untuk membuat subquery lebih mudah dibaca dengan memberinya nama, dan **UNION** untuk menggabungkan hasil dua query berbeda menjadi satu.

## CTE — Common Table Expression

Subquery bertingkat (subquery di dalam subquery) bisa cepat jadi sulit dibaca. **CTE** memungkinkan kamu mendefinisikan subquery **di awal**, memberinya nama, lalu memakainya seperti tabel biasa di query utama:

```sql
WITH buku_mahal AS (
  SELECT * FROM buku WHERE harga > 90000
)
SELECT judul, kategori FROM buku_mahal WHERE kategori = 'Teknologi';
```

Dibandingkan menulis subquery bersarang di `FROM`:

```sql
-- Versi tanpa CTE — sama hasilnya, tapi mulai sulit dibaca kalau logikanya bertambah rumit
SELECT judul, kategori
FROM (SELECT * FROM buku WHERE harga > 90000) AS buku_mahal
WHERE kategori = 'Teknologi';
```

Untuk query sederhana, keduanya sama saja. Tapi CTE jadi jauh lebih berguna ketika kamu punya **beberapa** subquery bertingkat, atau ingin memakai hasil subquery yang sama **lebih dari sekali** dalam satu query.

## CTE dengan Banyak Definisi

```sql
WITH
  ringkasan_kategori AS (
    SELECT kategori, AVG(harga) AS rata_rata FROM buku GROUP BY kategori
  ),
  kategori_mahal AS (
    SELECT kategori FROM ringkasan_kategori WHERE rata_rata > 85000
  )
SELECT judul, kategori FROM buku WHERE kategori IN (SELECT kategori FROM kategori_mahal);
```

## UNION — Menggabungkan Hasil Dua Query

`UNION` menggabungkan hasil dua (atau lebih) query `SELECT` menjadi satu daftar, dan **menghilangkan duplikat** secara otomatis:

```sql
-- Judul buku yang sangat murah ATAU sangat mahal
SELECT judul FROM buku WHERE harga < 60000
UNION
SELECT judul FROM buku WHERE harga > 110000;
```

:::warning
Kedua query yang digabung `UNION` harus punya **jumlah kolom yang sama**, dengan tipe data yang sesuai. Nama kolom hasil mengikuti query **pertama**.
:::

## UNION ALL — Menyimpan Duplikat

Kalau kamu tahu tidak akan ada duplikat (atau justru ingin menyimpannya untuk efisiensi/keperluan tertentu), pakai `UNION ALL` — lebih cepat karena tidak perlu memeriksa duplikat:

```sql
SELECT judul, 'Murah' AS label FROM buku WHERE harga < 60000
UNION ALL
SELECT judul, 'Mahal' AS label FROM buku WHERE harga > 110000;
```

Menambahkan kolom label seperti `'Murah'`/`'Mahal'` (nilai teks tetap, bukan dari kolom) membantu membedakan baris itu berasal dari query yang mana.

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| CTE | `WITH nama AS (SELECT ...) SELECT ... FROM nama;` |
| Banyak CTE | `WITH a AS (...), b AS (...) SELECT ...` |
| UNION | Gabung + hilangkan duplikat |
| UNION ALL | Gabung + simpan duplikat (lebih cepat) |
