# Mengenal SQLite & Playground

Ada banyak "mesin" database di dunia nyata: **MySQL**, **PostgreSQL**, **SQL Server**, **Oracle**, dan **SQLite**. Semuanya memahami bahasa SQL, tapi cara kerja dan tempat "hidup"-nya berbeda-beda.

## SQLite: Database Tanpa Server

Kebanyakan database (MySQL, PostgreSQL, dst) berjalan sebagai **server** terpisah — sebuah program yang harus dinyalakan dan didengarkan lewat jaringan, biasanya di komputer lain (server).

**SQLite** berbeda. Ia adalah database **embedded** (tertanam) — seluruh database hidup dalam satu file kecil, tanpa perlu server terpisah, tanpa instalasi rumit, tanpa proses login. Aplikasi ponsel, browser, bahkan aplikasi desktop banyak yang memakai SQLite untuk menyimpan data lokal.

<img src="/images/sqlite-in-browser.svg" alt="SQLite berjalan di browser lewat WebAssembly" width="100%" />

:::note
SQLite adalah database yang paling banyak dipakai di dunia — ada di hampir setiap ponsel Android/iOS, browser, dan jutaan aplikasi. Meskipun "kecil", ia sepenuhnya mendukung SQL standar.
:::

## Playground yang Berjalan di Browser

Di kursus ini, kita memakai library bernama **sql.js** — versi SQLite yang dikompilasi ke **WebAssembly (WASM)**, sebuah format yang membuat kode non-JavaScript bisa berjalan langsung di browser dengan kecepatan hampir seperti aplikasi native.

Artinya:

- **Tidak perlu install** database apapun di komputermu
- **Tidak perlu server** — semua query dijalankan langsung di browser
- **Tidak perlu API key** atau koneksi internet setelah halaman termuat
- Setiap kali kamu klik **Reset**, database dibuat ulang secara instan

```sql
-- Query ini akan dijalankan langsung di browser kamu, bukan di server manapun
SELECT * FROM buku;
```

:::tip
Karena semuanya berjalan di browser, kamu bisa bereksperimen sebebas mungkin — bahkan mencoba `DELETE` atau `DROP TABLE` — tanpa takut merusak data siapapun. Tinggal klik Reset untuk kembali ke awal.
:::

## Database, Tabel, dan Query — Istilah yang Sering Tertukar

| Istilah | Definisi | Analogi |
|---------|----------|---------|
| **Database** | Wadah yang berisi banyak tabel | Sebuah lemari arsip |
| **Tabel** | Struktur data berbentuk baris & kolom | Satu map/folder di dalam lemari |
| **Query** | Perintah SQL yang kamu tulis dan jalankan | Permintaan ke petugas arsip |

Sepanjang kursus ini, kita akan bekerja dengan satu database contoh bernama **`toko_buku`**, yang berisi tabel `buku` — supaya kamu bisa fokus belajar SQL tanpa perlu memikirkan skema baru setiap lesson.
