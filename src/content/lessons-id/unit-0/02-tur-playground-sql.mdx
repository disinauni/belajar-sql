# Tur Playground SQL

Saatnya mencoba langsung! Setiap lesson interaktif di kursus ini punya sebuah **playground** — kotak editor tempat kamu menulis dan menjalankan query SQL.

## Anatomi Playground

<img src="/images/playground-anatomy.svg" alt="Anatomi playground SQL: editor, tombol run, panel hasil" width="100%" />

Bagian-bagian utamanya:

- **Editor query** — tempat kamu mengetik SQL, dengan syntax highlighting
- **Tombol Run (▶)** — menjalankan query yang sedang kamu tulis
- **Tombol Reset** — mengembalikan query dan data ke kondisi awal
- **Panel hasil** — menampilkan hasil query sebagai tabel, atau pesan error jika ada yang salah

## Coba Jalankan Query Pertamamu

Di bawah ini ada playground sungguhan, sudah terisi database contoh `toko_buku`. Coba ketik query berikut (atau gunakan yang sudah tersedia), lalu klik **Jalankan**:

```sql
SELECT * FROM buku;
```

## Mencoba Reset

Sekarang coba ubah query di atas jadi ini, lalu jalankan:

```sql
DELETE FROM buku WHERE kategori = 'Fiksi';
```

Kamu akan melihat pesan **"N baris terpengaruh"** — artinya data benar-benar terhapus dari database yang sedang berjalan! Coba jalankan lagi `SELECT * FROM buku;` — buku-buku fiksi sudah hilang.

:::warning
Jangan panik — ini bukan data sungguhan di server manapun. Klik tombol **Reset** dan semua data akan kembali seperti semula, karena database dibuat ulang dari nol setiap kali di-reset.
:::

## Membaca Pesan Error

Playground ini menjalankan SQLite asli, jadi pesan error yang muncul juga pesan error SQLite yang sesungguhnya. Coba jalankan query yang salah tulis:

```sql
SELCT * FROM buku;
```

Kamu akan melihat pesan seperti `near "SELCT": syntax error` — SQLite memberitahu persis kata mana yang tidak ia kenali.

:::tip
Kalau menemui error, baca pesannya pelan-pelan. SQLite biasanya menunjuk kata atau tanda baca yang jadi sumber masalah dengan kata "near ...".
:::
