# Mengurutkan dengan ORDER BY

Tanpa `ORDER BY`, urutan baris hasil query **tidak dijamin** — SQLite bebas mengembalikannya dalam urutan apapun yang paling efisien baginya. Kalau kamu butuh urutan tertentu, gunakan `ORDER BY`.

## Urutan Menaik (ASC) dan Menurun (DESC)

```sql
-- Urutkan dari harga termurah ke termahal (menaik / ascending)
SELECT judul, harga
FROM buku
ORDER BY harga ASC;
```

```sql
-- Urutkan dari harga termahal ke termurah (menurun / descending)
SELECT judul, harga
FROM buku
ORDER BY harga DESC;
```

<img src="/images/order-by-comparison.svg" alt="Perbandingan ASC vs DESC" width="100%" />

:::note
`ASC` (ascending/menaik) adalah default — kalau kamu tulis `ORDER BY harga` saja tanpa `ASC`/`DESC`, SQLite otomatis mengurutkan menaik.
:::

## Mengurutkan Berdasarkan Teks

Kolom teks diurutkan secara alfabetis:

```sql
SELECT judul, penulis
FROM buku
ORDER BY judul ASC;
```

## Mengurutkan Berdasarkan Banyak Kolom

Kamu bisa mengurutkan berdasarkan lebih dari satu kolom — kolom kedua dipakai sebagai "pemutus seri" kalau kolom pertama nilainya sama:

```sql
-- Urutkan per kategori (alfabetis), lalu di dalam tiap kategori urutkan dari termahal
SELECT kategori, judul, harga
FROM buku
ORDER BY kategori ASC, harga DESC;
```

## Kombinasi dengan WHERE

`WHERE` dan `ORDER BY` bisa dipakai bersamaan — urutan penulisannya selalu `WHERE` dulu, baru `ORDER BY`:

```sql
SELECT judul, harga
FROM buku
WHERE kategori = 'Fiksi'
ORDER BY harga DESC;
```

## Kesalahan Umum

**1. Menaruh ORDER BY sebelum WHERE:**
```sql
SELECT judul FROM buku ORDER BY harga WHERE kategori = 'Fiksi';  -- ERROR: urutan salah
```
Urutan yang benar: `SELECT ... FROM ... WHERE ... ORDER BY ...`

**2. Mengandalkan urutan tanpa ORDER BY:**
```sql
SELECT * FROM buku;  -- urutan baris TIDAK dijamin konsisten
```

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Urutan menaik | `ORDER BY harga ASC` (atau cukup `ORDER BY harga`) |
| Urutan menurun | `ORDER BY harga DESC` |
| Banyak kolom | `ORDER BY kategori ASC, harga DESC` |
| Urutan klausa | `SELECT ... FROM ... WHERE ... ORDER BY ...` |

Selanjutnya: membatasi jumlah baris hasil dengan **LIMIT** — berguna untuk query "top N"!
