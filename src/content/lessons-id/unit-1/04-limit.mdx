# Membatasi Hasil dengan LIMIT

Kadang kamu hanya butuh beberapa baris teratas, bukan semuanya — misalnya "5 buku terlaris" atau "3 buku termahal". Di sinilah `LIMIT` berguna.

## LIMIT Dasar

```sql
-- Ambil 5 baris pertama saja, urutan apa adanya
SELECT judul FROM buku LIMIT 5;
```

## Pola "Top N": LIMIT + ORDER BY

`LIMIT` paling berguna ketika digabung dengan `ORDER BY` — inilah pola **"top N"** yang sangat umum dipakai:

<img src="/images/limit-offset-diagram.svg" alt="LIMIT dan OFFSET pada hasil query" width="100%" />

```sql
-- 3 buku termahal
SELECT judul, harga
FROM buku
ORDER BY harga DESC
LIMIT 3;
```

```sql
-- 3 buku dengan stok tersedikit
SELECT judul, stok
FROM buku
ORDER BY stok ASC
LIMIT 3;
```

:::warning
`LIMIT` tanpa `ORDER BY` tidak bisa diandalkan untuk "top N" — karena urutan baris tanpa ORDER BY tidak dijamin. Selalu gabungkan keduanya kalau kamu butuh "N teratas" yang konsisten.
:::

## OFFSET: Melompati Sejumlah Baris

`OFFSET` dipakai bersama `LIMIT` untuk melompati sejumlah baris pertama — berguna untuk fitur seperti "halaman 2" pada daftar:

```sql
-- Lewati 3 buku termahal pertama, tampilkan 3 buku berikutnya (peringkat 4-6)
SELECT judul, harga
FROM buku
ORDER BY harga DESC
LIMIT 3 OFFSET 3;
```

## Anatomi LIMIT

```sql
SELECT judul FROM buku ORDER BY harga DESC LIMIT 3;
```

Urutan klausa lengkap sampai sejauh ini: `SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT ...`

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Batasi jumlah baris | `LIMIT 5` |
| Top N | `ORDER BY harga DESC LIMIT 3` |
| Lompati baris (paging) | `LIMIT 3 OFFSET 3` |
| Urutan klausa | `SELECT...FROM...WHERE...ORDER BY...LIMIT...` |

Selanjutnya: memberi nama sementara pada kolom hasil dengan **alias (AS)**.
