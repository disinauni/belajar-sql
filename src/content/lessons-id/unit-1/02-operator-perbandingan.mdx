# Operator Perbandingan

Selain `=`, SQL punya operator perbandingan lengkap yang bisa dipakai di klausa `WHERE` — mirip dengan operator matematika yang sudah kamu kenal.

## Daftar Operator Perbandingan

| Operator | Arti | Contoh |
|----------|------|--------|
| `=` | Sama dengan | `harga = 68000` |
| `<>` atau `!=` | Tidak sama dengan | `kategori <> 'Fiksi'` |
| `>` | Lebih besar dari | `harga > 80000` |
| `<` | Lebih kecil dari | `stok < 5` |
| `>=` | Lebih besar sama dengan | `tahun_terbit >= 2010` |
| `<=` | Lebih kecil sama dengan | `harga <= 70000` |

## Contoh Penggunaan

Buku yang terbit tahun 2010 atau lebih baru:

```sql
SELECT judul, tahun_terbit
FROM buku
WHERE tahun_terbit >= 2010;
```

Buku yang **bukan** kategori Fiksi:

```sql
SELECT judul, kategori
FROM buku
WHERE kategori <> 'Fiksi';
```

Buku dengan stok kurang dari 10 (mungkin perlu di-restock):

```sql
SELECT judul, stok
FROM buku
WHERE stok < 10;
```

:::tip
`<>` dan `!=` artinya persis sama: "tidak sama dengan". SQLite mendukung keduanya — pilih salah satu dan konsisten memakainya.
:::

## Operator Perbandingan pada Teks

Operator `>` dan `<` juga bisa dipakai pada teks — dibandingkan secara alfabetis:

```sql
-- Judul buku yang dimulai huruf setelah 'M' secara alfabet
SELECT judul FROM buku WHERE judul > 'M';
```

Namun perbandingan ini jarang dipakai untuk teks bebas — lebih sering dipakai untuk kolom angka atau tanggal.

## Kesalahan Umum

**1. Memakai `=` untuk "lebih dari":**
```sql
WHERE harga = 80000;   -- hanya cari yang PERSIS 80000
WHERE harga > 80000;   -- cari yang LEBIH DARI 80000 — beda arti!
```

**2. Salah arah tanda:**
```sql
WHERE 80000 > harga;  -- valid, tapi urutan dibalik: artinya "harga di bawah 80000"
```

Ini valid secara sintaks, tapi lebih mudah dibaca kalau kolom ditulis di kiri: `WHERE harga < 80000`.

## Ringkasan

| Operator | Arti |
|----------|------|
| `=` | Sama dengan |
| `<>` / `!=` | Tidak sama dengan |
| `>`, `<` | Lebih besar / lebih kecil |
| `>=`, `<=` | Lebih besar/kecil sama dengan |

Selanjutnya: bagaimana cara **mengurutkan** hasil query dengan `ORDER BY`.
