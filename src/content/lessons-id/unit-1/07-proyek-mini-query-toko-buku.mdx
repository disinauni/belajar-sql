# Proyek Mini: Query Toko Buku

Selamat sampai di penghujung Unit 1! Saatnya menggabungkan semua yang sudah kamu pelajari — `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `AS`, dan `DISTINCT` — untuk menjawab pertanyaan-pertanyaan realistis seperti yang biasa dihadapi seorang admin toko buku online.

## Urutan Klausa Lengkap

Sejauh ini, urutan penulisan klausa SELECT yang benar adalah:

```sql
SELECT kolom1, kolom2 AS alias
FROM tabel
WHERE kondisi
ORDER BY kolom ASC/DESC
LIMIT n;
```

<img src="/images/query-execution-order.svg" alt="Urutan evaluasi klausa query SQL" width="100%" />

Menariknya, urutan **penulisan** ini berbeda dari urutan **evaluasi** SQLite di baliknya: SQLite sebenarnya memproses `FROM` dan `WHERE` terlebih dulu (menentukan baris mana yang relevan), baru kemudian `SELECT` (memilih kolom), lalu `ORDER BY`, dan terakhir `LIMIT`. Tapi untuk sekarang, cukup ingat urutan **penulisan**-nya saja.

## Studi Kasus: Pertanyaan Admin Toko Buku

**Pertanyaan 1: "Buku fiksi apa saja yang harganya di bawah 80000, urutkan termurah dulu?"**

```sql
SELECT judul, harga
FROM buku
WHERE kategori = 'Fiksi' AND harga < 80000
ORDER BY harga ASC;
```

:::note
`AND` menggabungkan dua kondisi WHERE sekaligus — baris harus memenuhi **keduanya**. Kita akan bahas operator logika ini lebih dalam di Unit 2, tapi kamu sudah bisa mulai memakainya sekarang.
:::

**Pertanyaan 2: "3 buku dengan stok paling sedikit, tampilkan sebagai laporan restock?"**

```sql
SELECT judul AS "Judul Buku", stok AS "Stok Tersisa"
FROM buku
ORDER BY stok ASC
LIMIT 3;
```

**Pertanyaan 3: "Apa saja kategori buku yang tersedia di toko?"**

```sql
SELECT DISTINCT kategori FROM buku;
```

## Refleksi: Apa yang Sudah Kamu Kuasai

| Klausa/Konsep | Fungsi |
|---------------|--------|
| `SELECT` | Memilih kolom yang ditampilkan |
| `FROM` | Menentukan tabel sumber data |
| `WHERE` | Menyaring baris berdasarkan kondisi |
| Operator perbandingan | `=`, `<>`, `>`, `<`, `>=`, `<=` |
| `ORDER BY` | Mengurutkan hasil (ASC/DESC) |
| `LIMIT` / `OFFSET` | Membatasi & melompati jumlah baris |
| `AS` | Memberi alias pada kolom/tabel |
| `DISTINCT` | Menghilangkan baris duplikat |

Kamu baru saja menguasai fondasi SELECT dasar — modal utama untuk hampir semua pekerjaan dengan SQL! Di **Unit 2 (Filtering & Operator)**, kita akan memperdalam WHERE dengan operator logika (`AND`/`OR`/`NOT`), `LIKE`, `IN`, `BETWEEN`, dan cara menangani nilai `NULL`.
