# Memfilter dengan WHERE

Tanpa `WHERE`, `SELECT` selalu mengembalikan **semua baris** di tabel. Klausa `WHERE` memungkinkan kamu menyaring — hanya baris yang memenuhi kondisi tertentu yang ditampilkan.

## Alur Evaluasi WHERE

<img src="/images/where-filter-flow.svg" alt="Alur filter WHERE: baris diperiksa satu per satu" width="100%" />

SQLite memeriksa **setiap baris satu per satu**: jika kondisi WHERE bernilai benar untuk baris itu, baris itu masuk ke hasil. Jika tidak, baris itu dilewati.

## Filter Berdasarkan Angka

```sql
SELECT judul, harga
FROM buku
WHERE harga > 80000;
```

Hanya buku dengan harga lebih dari 80000 yang muncul.

## Filter Berdasarkan Teks

Nilai teks (string) harus diapit tanda kutip tunggal `'...'`:

```sql
SELECT judul, kategori
FROM buku
WHERE kategori = 'Fiksi';
```

:::warning
Lupa tanda kutip pada nilai teks adalah kesalahan paling umum:
```sql
WHERE kategori = Fiksi;  -- ERROR: SQLite mengira Fiksi adalah nama kolom
```
Selalu gunakan tanda kutip: `WHERE kategori = 'Fiksi'`.
:::

## Filter dengan Kesetaraan Persis

Operator `=` mencari nilai yang **persis sama**:

```sql
SELECT * FROM buku WHERE penulis = 'Tere Liye';
```

Kalau kamu salah ketik huruf besar/kecil atau spasi, tidak akan ada hasil yang cocok (SQLite peka terhadap ejaan persis, meskipun perbandingan teks di SQLite defaultnya tidak case-sensitive untuk huruf ASCII).

## Anatomi WHERE

```sql
SELECT judul FROM buku WHERE harga > 80000;
```

- **`WHERE`** — mulai kondisi penyaringan
- **`harga > 80000`** — ekspresi kondisi: kolom, operator, nilai pembanding
- Baris hanya ditampilkan jika ekspresi ini bernilai **benar (true)**

## Kesalahan Umum

**1. Menaruh WHERE sebelum FROM:**
```sql
SELECT judul WHERE harga > 80000 FROM buku;  -- ERROR: urutan salah
```
Urutan yang benar selalu: `SELECT ... FROM ... WHERE ...`

**2. Lupa tanda kutip pada teks:**
```sql
WHERE judul = Sapiens;  -- ERROR
```

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Filter angka | `WHERE harga > 80000` |
| Filter teks | `WHERE kategori = 'Fiksi'` |
| Urutan klausa | `SELECT ... FROM ... WHERE ...` |
| Nilai teks | Selalu diapit tanda kutip tunggal `'...'` |

Selanjutnya kita akan pelajari **operator perbandingan lengkap** — lebih dari sekadar `=` dan `>`!
