# Operator BETWEEN

`BETWEEN` menyaring nilai yang berada dalam sebuah rentang — alternatif yang lebih ringkas daripada menulis dua kondisi `>=` dan `<=` sekaligus.

## BETWEEN Dasar

```sql
-- Setara dengan: harga >= 60000 AND harga <= 90000
SELECT judul, harga
FROM buku
WHERE harga BETWEEN 60000 AND 90000;
```

## BETWEEN Bersifat Inklusif

Kedua ujung rentang **ikut disertakan** dalam hasil — buku dengan harga persis 60000 atau persis 90000 tetap muncul.

```sql
SELECT judul, tahun_terbit
FROM buku
WHERE tahun_terbit BETWEEN 2004 AND 2011;
```

:::note
`BETWEEN 60000 AND 90000` selalu ditulis dengan nilai **kecil dulu, besar kemudian**. Membalik urutan (`BETWEEN 90000 AND 60000`) tidak menghasilkan error, tapi hasilnya akan selalu kosong karena SQLite mengartikannya sebagai `nilai >= 90000 AND nilai <= 60000` yang mustahil terpenuhi.
:::

## NOT BETWEEN

```sql
-- Buku dengan harga di LUAR rentang 60000-90000
SELECT judul, harga
FROM buku
WHERE harga NOT BETWEEN 60000 AND 90000;
```

## BETWEEN vs Operator Perbandingan

`BETWEEN` hanyalah gula sintaksis (syntactic sugar) — dua query berikut identik hasilnya:

```sql
SELECT judul FROM buku WHERE harga BETWEEN 60000 AND 90000;
SELECT judul FROM buku WHERE harga >= 60000 AND harga <= 90000;
```

Pilih `BETWEEN` saat rentangnya jelas dan tunggal — pilih `AND` manual saat butuh kombinasi kondisi yang lebih rumit.

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Rentang inklusif | `harga BETWEEN 60000 AND 90000` |
| Kebalikan | `harga NOT BETWEEN 60000 AND 90000` |
| Setara dengan | `harga >= 60000 AND harga <= 90000` |

Selanjutnya: menangani nilai kosong dengan **NULL**.
