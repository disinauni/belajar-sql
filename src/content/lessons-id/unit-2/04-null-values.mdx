# Menangani NULL

Tabel `buku` yang kita pakai sejak Unit 1 kebetulan tidak punya kolom kosong sama sekali. Tapi di dunia nyata, data yang belum diisi itu biasa — misalnya pelanggan yang belum mengisi email. Lesson ini memakai tabel contoh baru: `pelanggan (id, nama, email)`.

| id | nama | email |
|----|------|-------|
| 1 | Dewi | dewi@email.com |
| 2 | Farhan | *(NULL)* |
| 3 | Citra | citra@email.com |
| 4 | Budi | *(NULL)* |
| 5 | Eka | eka@email.com |

## NULL Bukan Nol, Bukan String Kosong

`NULL` berarti **"tidak ada nilai sama sekali"** — beda dengan angka 0 atau teks kosong `''`. Farhan dan Budi belum mengisi email; kolom email mereka bukan bertuliskan `""` atau `"0"`, tapi benar-benar kosong.

```sql
-- ERROR secara logika — ini TIDAK akan menemukan baris NULL sama sekali!
SELECT * FROM pelanggan WHERE email = NULL;
```

:::warning
`= NULL` **tidak pernah bernilai true**, bahkan untuk baris yang emailnya memang NULL! Operator perbandingan biasa (`=`, `<>`) tidak bisa dipakai untuk NULL — SQL punya operator khusus: `IS NULL` dan `IS NOT NULL`.
:::

## IS NULL & IS NOT NULL

```sql
-- Pelanggan yang BELUM mengisi email
SELECT nama FROM pelanggan WHERE email IS NULL;
```

```sql
-- Pelanggan yang SUDAH mengisi email
SELECT nama, email FROM pelanggan WHERE email IS NOT NULL;
```

## COALESCE — Nilai Pengganti untuk NULL

Fungsi `COALESCE()` mengembalikan nilai pertama yang bukan NULL dari daftar argumennya — berguna untuk menampilkan teks pengganti:

```sql
SELECT nama, COALESCE(email, '(belum diisi)') AS email
FROM pelanggan;
```

Baris dengan email NULL akan tampil sebagai "(belum diisi)", sementara baris lain tetap menampilkan emailnya.

:::tip
NULL juga "menular" dalam perhitungan: `harga * NULL` hasilnya NULL, bukan 0. Kalau kamu menjumlahkan kolom yang mengandung NULL dengan `SUM()`, SQLite otomatis mengabaikan baris NULL itu (dibahas lebih lanjut di Unit 3).
:::

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Cek kosong | `WHERE email IS NULL` |
| Cek terisi | `WHERE email IS NOT NULL` |
| Nilai pengganti | `COALESCE(email, '(belum diisi)')` |
| Jebakan umum | `WHERE email = NULL` — **tidak pernah bekerja** |
