# Proyek Mini: Filter Lanjutan

Selamat sampai di akhir Unit 2! Sekarang kamu punya perangkat filtering lengkap: `AND`/`OR`/`NOT`, `LIKE`, `IN`, `BETWEEN`, dan `IS NULL`. Mari gabungkan semuanya untuk menjawab pertanyaan admin toko buku yang lebih realistis.

## Memilih Operator yang Tepat

| Kebutuhan | Operator |
|-----------|----------|
| Beberapa kondisi harus semua benar | `AND` |
| Salah satu dari beberapa kondisi cukup | `OR` |
| Mencari pola/potongan teks | `LIKE '%...%'` |
| Cocok dengan salah satu dari daftar nilai | `IN (...)` |
| Nilai dalam rentang tertentu | `BETWEEN ... AND ...` |
| Kolom kosong/terisi | `IS NULL` / `IS NOT NULL` |

## Studi Kasus

**"Buku Fiksi atau Non-Fiksi, dengan harga antara 60000 dan 100000, yang judulnya tidak mengandung kata 'Cinta'"**

```sql
SELECT judul, kategori, harga
FROM buku
WHERE kategori IN ('Fiksi', 'Non-Fiksi')
  AND harga BETWEEN 60000 AND 100000
  AND judul NOT LIKE '%Cinta%';
```

Perhatikan bagaimana `IN` menggantikan `OR` berulang, dan `BETWEEN` menggantikan dua kondisi `>=`/`<=`, sehingga query tetap ringkas meski menggabungkan banyak syarat.

## Ringkasan Unit 2

| Konsep | Operator |
|--------|----------|
| Logika gabungan | `AND`, `OR`, `NOT` |
| Pola teks | `LIKE`, wildcard `%` `_` |
| Daftar nilai | `IN`, `NOT IN` |
| Rentang nilai | `BETWEEN ... AND ...` |
| Nilai kosong | `IS NULL`, `IS NOT NULL`, `COALESCE` |

Di **Unit 3 (Agregasi & GROUP BY)**, kita akan belajar meringkas banyak baris menjadi satu angka — total penjualan, rata-rata harga, jumlah buku per kategori — dengan `COUNT`, `SUM`, `AVG`, dan `GROUP BY`.
