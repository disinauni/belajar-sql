# Menggabungkan Semua Klausa

Sekarang kamu sudah mengenal semua klausa utama `SELECT`. Saatnya melihat urutan penulisan lengkapnya sekaligus — dan memahami urutan **evaluasi** SQLite di baliknya, yang ternyata berbeda.

## Urutan Penulisan Lengkap

```sql
SELECT kolom, FUNGSI_AGREGAT(kolom) AS alias
FROM tabel
WHERE kondisi_baris
GROUP BY kolom_grouping
HAVING kondisi_agregat
ORDER BY kolom ASC/DESC
LIMIT n;
```

Setiap klausa bersifat opsional kecuali `SELECT` dan `FROM` — tapi kalau dipakai, urutan penulisannya **wajib** seperti di atas.

## Urutan Evaluasi Logis (Berbeda dari Urutan Penulisan!)

<img src="/images/aggregate-functions.svg" alt="Ringkasan fungsi agregat COUNT SUM AVG MIN MAX" width="100%" />

SQLite sebenarnya memproses klausa dengan urutan **logis** berikut, dari dalam ke luar:

1. **FROM** — tentukan tabel sumber
2. **WHERE** — saring baris mentah
3. **GROUP BY** — kelompokkan baris yang tersisa
4. **HAVING** — saring hasil kelompok
5. **SELECT** — pilih/hitung kolom yang ditampilkan
6. **ORDER BY** — urutkan hasil akhir
7. **LIMIT** — batasi jumlah baris hasil akhir

Ini menjelaskan kenapa `WHERE` tidak bisa memakai `COUNT(*)` (belum dihitung saat `WHERE` berjalan) tapi `HAVING` bisa (dihitung setelah `GROUP BY`).

## Contoh Lengkap

```sql
SELECT kategori, COUNT(*) AS jumlah, ROUND(AVG(harga), 0) AS rata_rata
FROM buku
WHERE stok > 0
GROUP BY kategori
HAVING COUNT(*) >= 2
ORDER BY rata_rata DESC
LIMIT 3;
```

Membaca query ini selangkah demi selangkah:
1. Ambil semua baris dari `buku`
2. Saring hanya yang `stok > 0`
3. Kelompokkan berdasarkan `kategori`
4. Hitung `COUNT(*)` dan `AVG(harga)` per kelompok
5. Saring: hanya kelompok dengan jumlah buku >= 2
6. Urutkan dari rata-rata harga tertinggi
7. Ambil 3 teratas saja

:::tip
Kalau bingung urutan klausa mana dulu, ingat singkatan **F-W-G-H-O-L**: **F**ROM, **W**HERE, **G**ROUP BY, **H**AVING, **O**RDER BY, **L**IMIT.
:::

## Ringkasan

| Klausa | Fungsi | Kapan dievaluasi |
|--------|--------|-------------------|
| `FROM` | Tabel sumber | 1 |
| `WHERE` | Saring baris mentah | 2 |
| `GROUP BY` | Kelompokkan baris | 3 |
| `HAVING` | Saring hasil kelompok | 4 |
| `SELECT` | Pilih/hitung kolom | 5 |
| `ORDER BY` | Urutkan hasil | 6 |
| `LIMIT` | Batasi jumlah baris | 7 |
