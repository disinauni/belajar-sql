# Menghitung Baris dengan COUNT

Sejauh ini, setiap query yang kita tulis mengembalikan **baris demi baris** data mentah. Tapi kadang kamu hanya butuh satu angka ringkasan — "berapa banyak buku yang kita punya?". Di sinilah **fungsi agregat** berperan: fungsi yang meringkas banyak baris menjadi satu nilai.

`COUNT` adalah fungsi agregat paling sederhana: menghitung jumlah baris.

## COUNT(*) — Menghitung Semua Baris

```sql
SELECT COUNT(*) FROM buku;
```

Output:
```
COUNT(*)
--------
12
```

Hanya satu baris, satu angka — beda total dengan `SELECT * FROM buku;` yang mengembalikan 12 baris data.

## COUNT dengan WHERE

`COUNT(*)` bisa digabung `WHERE` seperti biasa — filter dulu, baru dihitung:

```sql
-- Berapa banyak buku kategori Fiksi?
SELECT COUNT(*) FROM buku WHERE kategori = 'Fiksi';
```

## COUNT(kolom) vs COUNT(*)

`COUNT(nama_kolom)` menghitung baris yang kolom itu **tidak NULL**. Karena tabel `buku` tidak punya kolom NULL, `COUNT(*)` dan `COUNT(judul)` menghasilkan angka yang sama di sini — tapi kalau ada kolom yang boleh kosong (seperti `email` di lesson NULL sebelumnya), keduanya bisa berbeda.

```sql
-- Sama hasilnya di tabel buku (tidak ada kolom NULL)
SELECT COUNT(*) FROM buku;
SELECT COUNT(judul) FROM buku;
```

## COUNT(DISTINCT kolom) — Menghitung Nilai Unik

```sql
-- Berapa banyak kategori BERBEDA yang ada?
SELECT COUNT(DISTINCT kategori) FROM buku;
```

Ini menghitung jumlah nilai unik, bukan jumlah baris — mirip `SELECT DISTINCT kategori FROM buku;` tapi langsung menghasilkan angkanya saja.

## Memberi Alias pada Hasil COUNT

```sql
SELECT COUNT(*) AS jumlah_buku FROM buku;
```

Tanpa alias, nama kolom hasil akan tampil sebagai `COUNT(*)` apa adanya — kurang enak dibaca aplikasi lain. Selalu beri alias yang jelas.

:::tip
`COUNT(*)` menghitung baris tanpa peduli isi kolom apapun — bahkan kalau semua kolom di sebuah baris NULL, baris itu tetap terhitung. Beda dengan `COUNT(kolom)` yang mengabaikan baris NULL di kolom spesifik itu.
:::

## Ringkasan

| Fungsi | Menghitung |
|--------|-----------|
| `COUNT(*)` | Semua baris, tanpa peduli isi kolom |
| `COUNT(kolom)` | Baris yang kolom itu tidak NULL |
| `COUNT(DISTINCT kolom)` | Jumlah nilai unik pada kolom itu |

Selanjutnya: menjumlahkan dan merata-ratakan angka dengan **SUM** dan **AVG**.
