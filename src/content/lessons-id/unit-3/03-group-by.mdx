# Mengelompokkan dengan GROUP BY

Di lesson sebelumnya, fungsi agregat selalu meringkas **seluruh tabel** menjadi satu angka. Tapi pertanyaan yang lebih berguna biasanya per kelompok: "berapa banyak buku **di tiap kategori**?", bukan "berapa total buku semuanya?". `GROUP BY` membuat ini mungkin.

## GROUP BY Dasar

```sql
SELECT kategori, COUNT(*) AS jumlah
FROM buku
GROUP BY kategori;
```

Output:
```
kategori           | jumlah
-------------------+-------
Fiksi              | 6
Non-Fiksi          | 1
Pengembangan Diri  | 2
Teknologi          | 2
Keuangan           | 1
```

<img src="/images/group-by-having.svg" alt="GROUP BY mengelompokkan baris sebelum fungsi agregat dihitung" width="100%" />

SQLite mengelompokkan semua baris dengan `kategori` yang sama, lalu menjalankan `COUNT(*)` **per kelompok** — bukan satu angka untuk seluruh tabel.

## GROUP BY dengan Fungsi Agregat Lain

```sql
-- Rata-rata harga per kategori
SELECT kategori, ROUND(AVG(harga), 0) AS rata_rata_harga
FROM buku
GROUP BY kategori;
```

```sql
-- Total nilai stok per kategori
SELECT kategori, SUM(harga * stok) AS total_nilai
FROM buku
GROUP BY kategori;
```

## Aturan Penting: Kolom di SELECT

Saat memakai `GROUP BY`, setiap kolom di `SELECT` harus salah satu dari:
1. Kolom yang ada di `GROUP BY`, atau
2. Dibungkus fungsi agregat (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)

```sql
-- BENAR: kategori ada di GROUP BY, judul TIDAK ada — ini akan error atau tidak terdefinisi
SELECT kategori, judul, COUNT(*) FROM buku GROUP BY kategori;  -- ⚠️ judul ambigu!
```

```sql
-- BENAR: hanya kategori (di GROUP BY) dan COUNT(*) (fungsi agregat)
SELECT kategori, COUNT(*) FROM buku GROUP BY kategori;
```

:::warning
SQLite cenderung lebih permisif dibanding PostgreSQL/MySQL soal aturan ini — ia mungkin tetap menjalankan query dengan kolom "ambigu" tanpa error, tapi hasilnya bisa memilih baris sembarang dari tiap kelompok. Jangan andalkan perilaku ini — selalu ikuti aturan di atas.
:::

## GROUP BY dengan Banyak Kolom

```sql
-- Kelompokkan berdasarkan kombinasi kategori DAN tahun_terbit
SELECT kategori, tahun_terbit, COUNT(*) AS jumlah
FROM buku
GROUP BY kategori, tahun_terbit;
```

## GROUP BY dengan WHERE

`WHERE` menyaring baris **sebelum** dikelompokkan:

```sql
-- Hanya buku dengan stok > 0, dikelompokkan per kategori
SELECT kategori, COUNT(*) AS jumlah
FROM buku
WHERE stok > 0
GROUP BY kategori;
```

## Ringkasan

| Konsep | Contoh |
|--------|--------|
| Kelompokkan + hitung | `SELECT kategori, COUNT(*) FROM buku GROUP BY kategori;` |
| Banyak kolom grouping | `GROUP BY kategori, tahun_terbit` |
| Urutan klausa | `SELECT ... FROM ... WHERE ... GROUP BY ...` |
| Aturan SELECT | Kolom grouping ATAU fungsi agregat saja |

Selanjutnya: menyaring HASIL pengelompokan (bukan baris mentah) dengan **HAVING**.
