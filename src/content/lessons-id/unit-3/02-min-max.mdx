# MIN & MAX

`MIN` dan `MAX` adalah fungsi agregat untuk mencari nilai terkecil dan terbesar pada sebuah kolom.

## MIN & MAX pada Angka

```sql
SELECT MIN(harga) AS termurah, MAX(harga) AS termahal FROM buku;
```

Satu query bisa langsung menghasilkan dua angka ringkasan sekaligus — harga termurah dan termahal.

```sql
SELECT MIN(tahun_terbit) AS tertua, MAX(tahun_terbit) AS terbaru FROM buku;
```

## MIN/MAX Bukan Cuma untuk Angka

`MIN`/`MAX` juga bekerja pada kolom teks (alfabetis) dan tanggal (kronologis):

```sql
-- Judul paling awal dan paling akhir secara alfabetis
SELECT MIN(judul) AS judul_pertama_abjad, MAX(judul) AS judul_terakhir_abjad
FROM buku;
```

## Mencari Baris Lengkap dengan Nilai MIN/MAX

`MIN(harga)` hanya mengembalikan **angkanya saja**, bukan seluruh baris buku itu. Untuk mengetahui buku *mana* yang termurah lengkap dengan semua kolomnya, gabungkan dengan `ORDER BY` + `LIMIT` (dari Unit 1) — bukan `MIN()`:

```sql
-- Cara mendapatkan angka termurah saja
SELECT MIN(harga) FROM buku;

-- Cara mendapatkan BARIS buku termurah lengkap
SELECT * FROM buku ORDER BY harga ASC LIMIT 1;
```

:::tip
Ini kesalahan pemula yang umum: mengira `SELECT judul, MIN(harga) FROM buku` akan menampilkan judul buku termurah. Padahal itu mencampur kolom biasa dengan fungsi agregat tanpa `GROUP BY` — hasilnya tidak terdefinisi dengan baik. Kita akan bahas kenapa di lesson **GROUP BY** berikutnya.
:::

## MIN/MAX dengan WHERE

```sql
-- Harga termahal khusus kategori Fiksi
SELECT MAX(harga) AS termahal_fiksi FROM buku WHERE kategori = 'Fiksi';
```

## Ringkasan

| Fungsi | Kegunaan |
|--------|----------|
| `MIN(kolom)` | Nilai terkecil (angka) atau paling awal (teks/tanggal) |
| `MAX(kolom)` | Nilai terbesar (angka) atau paling akhir (teks/tanggal) |
| Baris lengkap termin/termax | Pakai `ORDER BY` + `LIMIT 1`, bukan `MIN()`/`MAX()` |

Sekarang kamu punya 5 fungsi agregat: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Selanjutnya kita belajar **GROUP BY** — cara mengelompokkan baris supaya fungsi agregat ini bisa dihitung per kelompok, bukan cuma satu angka untuk seluruh tabel.
