# SUM & AVG

Setelah `COUNT`, dua fungsi agregat paling sering dipakai adalah `SUM` (menjumlahkan) dan `AVG` (rata-rata). Keduanya hanya bekerja pada kolom **angka**.

## SUM — Menjumlahkan

```sql
-- Total nilai seluruh stok buku (dalam satuan buku, bukan rupiah)
SELECT SUM(stok) FROM buku;
```

```sql
-- Total nilai inventaris (harga x stok, dijumlahkan semua baris)
SELECT SUM(harga * stok) AS total_nilai_inventaris FROM buku;
```

## AVG — Rata-Rata

```sql
SELECT AVG(harga) FROM buku;
```

Output akan berupa angka desimal (misalnya `81416.666...`) karena rata-rata jarang berupa bilangan bulat.

## Membulatkan dengan ROUND

Fungsi `ROUND(nilai, jumlah_desimal)` membulatkan angka supaya lebih rapi ditampilkan:

```sql
SELECT ROUND(AVG(harga), 0) AS rata_rata_harga FROM buku;
```

## SUM/AVG dengan WHERE

Sama seperti `COUNT`, `SUM`/`AVG` bisa digabung `WHERE` — filter dulu, baru dihitung:

```sql
-- Rata-rata harga buku kategori Fiksi saja
SELECT ROUND(AVG(harga), 0) AS rata_rata_fiksi
FROM buku
WHERE kategori = 'Fiksi';
```

:::note
`SUM` dan `AVG` **mengabaikan baris NULL** secara otomatis. Kalau ada 10 baris tapi 2 di antaranya NULL pada kolom yang dijumlahkan, `AVG` akan membagi total dengan 8 (bukan 10) — hanya baris yang punya nilai yang dihitung.
:::

:::warning
`SUM`/`AVG` hanya masuk akal untuk kolom angka. `SUM(judul)` pada kolom teks akan menghasilkan error atau nilai yang tidak berguna, tergantung RDBMS-nya.
:::

## Ringkasan

| Fungsi | Kegunaan |
|--------|----------|
| `SUM(kolom)` | Menjumlahkan semua nilai |
| `AVG(kolom)` | Menghitung rata-rata |
| `ROUND(nilai, n)` | Membulatkan ke n desimal |
| Perilaku NULL | Diabaikan dari perhitungan |

Selanjutnya: mencari nilai terkecil dan terbesar dengan **MIN** dan **MAX**.
