# Proyek Mini: Laporan Penjualan

Selamat sampai di akhir Unit 3! Sekarang kamu bisa mengubah data mentah jadi **laporan ringkasan** — persis seperti yang dibutuhkan admin toko buku untuk mengambil keputusan bisnis.

## Perangkat yang Sudah Kamu Kuasai

| Fungsi/Klausa | Kegunaan |
|---------------|----------|
| `COUNT(*)` | Menghitung jumlah baris |
| `SUM(kolom)` | Menjumlahkan nilai |
| `AVG(kolom)` | Menghitung rata-rata |
| `MIN`/`MAX(kolom)` | Nilai terkecil/terbesar |
| `GROUP BY` | Mengelompokkan baris untuk dihitung per kelompok |
| `HAVING` | Menyaring hasil kelompok berdasarkan agregat |

## Studi Kasus: Laporan Kategori

**"Untuk tiap kategori, tampilkan jumlah judul, total nilai stok, dan harga rata-rata — hanya kategori dengan minimal 2 judul, urutkan dari total nilai stok tertinggi"**

```sql
SELECT
  kategori,
  COUNT(*) AS jumlah_judul,
  SUM(harga * stok) AS total_nilai_stok,
  ROUND(AVG(harga), 0) AS rata_rata_harga
FROM buku
GROUP BY kategori
HAVING COUNT(*) >= 2
ORDER BY total_nilai_stok DESC;
```

Satu query ini menjawab pertanyaan yang kalau dikerjakan manual di spreadsheet bisa makan waktu berjam-jam.

## Refleksi: Apa yang Sudah Kamu Kuasai

| Konsep | Fungsi |
|--------|--------|
| `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` | Meringkas banyak baris jadi satu nilai |
| `GROUP BY` | Menghitung agregat per kelompok, bukan per seluruh tabel |
| `HAVING` | Menyaring hasil kelompok berdasarkan nilai agregat |
| Urutan F-W-G-H-O-L | `FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT` |

Kamu sekarang bisa membuat laporan bisnis nyata dari data mentah! Di **Unit 4 (JOIN)**, kita naik level lagi: menggabungkan data dari **lebih dari satu tabel** sekaligus — fondasi untuk bekerja dengan database dunia nyata yang selalu terdiri dari banyak tabel yang saling berhubungan.
