# Column & Table Aliases with AS

Sometimes the original column name isn't pleasant to read in a report, or you want to give a calculated result a more descriptive name. The `AS` keyword creates an **alias** — a temporary name that only applies while that query runs.

## Column Aliases

```sql
SELECT judul AS nama_buku, harga AS harga_rupiah
FROM buku;
```

The result: the column formerly named `judul` now displays with the header `nama_buku` — but this is **display only**, the actual column name in the table doesn't change at all.

```sql
-- Aliases with spaces need double quotes or brackets
SELECT judul AS "Judul Buku", harga AS "Harga (Rp)"
FROM buku;
```

:::note
`AS` is actually optional in SQLite — `SELECT judul nama_buku FROM buku` works the same way. But writing `AS` explicitly makes queries much easier to read, so make it a habit to always write it out.
:::

## Why Aliases Are Useful

Aliases are especially helpful when a result column isn't just a raw column, but a calculation or expression:

```sql
-- Without an alias, the calculated column's name would look odd/long
SELECT judul, harga * stok AS total_nilai_stok
FROM buku;
```

Without `AS total_nilai_stok`, that multiplication result column would get an automatic name like `harga * stok`, which is messy for other applications to read.

## A Preview: Table Aliases

`AS` can also give an alias to a **table name** — this will be very useful later when we learn `JOIN` in Unit 4, since writing a long table name over and over gets tedious:

```sql
SELECT b.judul, b.harga
FROM buku AS b
WHERE b.harga > 80000;
```

Here `b` is an alias for the `buku` table, and `b.judul` means "the judul column from the table aliased b".

:::tip
For now (since we only have one table), table aliases won't feel very useful yet. Keep this concept in mind — it'll help a lot once queries involve multiple tables at once.
:::

## Summary

| Concept | Example |
|---------|---------|
| Column alias | `SELECT judul AS nama_buku FROM buku;` |
| Alias with spaces | `SELECT harga AS "Harga (Rp)" FROM buku;` |
| Alias on a calculation | `SELECT harga * stok AS total_nilai FROM buku;` |
| Table alias | `FROM buku AS b` |
