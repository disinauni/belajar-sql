# Sorting with ORDER BY

Without `ORDER BY`, the row order of a query result is **not guaranteed** — SQLite is free to return rows in whatever order is most efficient for it. If you need a specific order, use `ORDER BY`.

## Ascending (ASC) and Descending (DESC)

```sql
-- Sort from cheapest to most expensive (ascending)
SELECT judul, harga
FROM buku
ORDER BY harga ASC;
```

```sql
-- Sort from most expensive to cheapest (descending)
SELECT judul, harga
FROM buku
ORDER BY harga DESC;
```

<img src="/images/order-by-comparison.svg" alt="ASC vs DESC comparison" width="100%" />

:::note
`ASC` (ascending) is the default — if you write `ORDER BY harga` alone without `ASC`/`DESC`, SQLite sorts ascending automatically.
:::

## Sorting by Text

Text columns are sorted alphabetically:

```sql
SELECT judul, penulis
FROM buku
ORDER BY judul ASC;
```

## Sorting by Multiple Columns

You can sort by more than one column — the second column acts as a "tiebreaker" when the first column's values are equal:

```sql
-- Sort by category (alphabetically), then within each category by price descending
SELECT kategori, judul, harga
FROM buku
ORDER BY kategori ASC, harga DESC;
```

## Combining with WHERE

`WHERE` and `ORDER BY` can be used together — the writing order is always `WHERE` first, then `ORDER BY`:

```sql
SELECT judul, harga
FROM buku
WHERE kategori = 'Fiksi'
ORDER BY harga DESC;
```

## Common Mistakes

**1. Placing ORDER BY before WHERE:**
```sql
SELECT judul FROM buku ORDER BY harga WHERE kategori = 'Fiksi';  -- ERROR: wrong order
```
The correct order: `SELECT ... FROM ... WHERE ... ORDER BY ...`

**2. Relying on order without ORDER BY:**
```sql
SELECT * FROM buku;  -- row order is NOT guaranteed to be consistent
```

## Summary

| Concept | Example |
|---------|---------|
| Ascending order | `ORDER BY harga ASC` (or just `ORDER BY harga`) |
| Descending order | `ORDER BY harga DESC` |
| Multiple columns | `ORDER BY kategori ASC, harga DESC` |
| Clause order | `SELECT ... FROM ... WHERE ... ORDER BY ...` |
