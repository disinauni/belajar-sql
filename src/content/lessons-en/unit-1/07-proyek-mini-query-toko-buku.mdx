# Mini Project: Bookstore Queries

Congratulations on reaching the end of Unit 1! Time to combine everything you've learned — `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `AS`, and `DISTINCT` — to answer realistic questions like the ones an online bookstore admin deals with every day.

## Full Clause Order

So far, the correct SELECT clause writing order is:

```sql
SELECT column1, column2 AS alias
FROM table
WHERE condition
ORDER BY column ASC/DESC
LIMIT n;
```

<img src="/images/query-execution-order.svg" alt="SQL query clause evaluation order" width="100%" />

Interestingly, this **writing** order differs from SQLite's actual **evaluation** order under the hood: SQLite actually processes `FROM` and `WHERE` first (determining which rows are relevant), then `SELECT` (choosing columns), then `ORDER BY`, and finally `LIMIT`. For now, just remember the **writing** order.

## Case Study: A Bookstore Admin's Questions

**Question 1: "Which fiction books are priced under 80000, sorted cheapest first?"**

```sql
SELECT judul, harga
FROM buku
WHERE kategori = 'Fiksi' AND harga < 80000
ORDER BY harga ASC;
```

:::note
`AND` combines two WHERE conditions at once — a row must satisfy **both**. We'll dig deeper into this logical operator in Unit 2, but you can already start using it now.
:::

**Question 2: "The 3 books with the lowest stock, for a restock report?"**

```sql
SELECT judul AS "Judul Buku", stok AS "Stok Tersisa"
FROM buku
ORDER BY stok ASC
LIMIT 3;
```

**Question 3: "What book categories does the store carry?"**

```sql
SELECT DISTINCT kategori FROM buku;
```

## Reflection: What You've Mastered

| Clause/Concept | Function |
|-----------------|----------|
| `SELECT` | Choose which columns to display |
| `FROM` | Specify the source table |
| `WHERE` | Filter rows by a condition |
| Comparison operators | `=`, `<>`, `>`, `<`, `>=`, `<=` |
| `ORDER BY` | Sort results (ASC/DESC) |
| `LIMIT` / `OFFSET` | Limit & skip a number of rows |
| `AS` | Alias a column/table |
| `DISTINCT` | Remove duplicate rows |

You've just mastered the foundations of basic SELECT — the core skill behind almost all SQL work! In **Unit 2 (Filtering & Operators)**, we'll go deeper into WHERE with logical operators (`AND`/`OR`/`NOT`), `LIKE`, `IN`, `BETWEEN`, and how to handle `NULL` values.
