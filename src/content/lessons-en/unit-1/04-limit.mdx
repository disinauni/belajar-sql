# Limiting Results with LIMIT

Sometimes you only need a handful of top rows, not everything — e.g. "top 5 best sellers" or "3 most expensive books". That's where `LIMIT` comes in.

## Basic LIMIT

```sql
-- Take only the first 5 rows, in whatever order they come
SELECT judul FROM buku LIMIT 5;
```

## The "Top N" Pattern: LIMIT + ORDER BY

`LIMIT` is most useful combined with `ORDER BY` — this is the very common **"top N"** pattern:

<img src="/images/limit-offset-diagram.svg" alt="LIMIT and OFFSET over a result set" width="100%" />

```sql
-- 3 most expensive books
SELECT judul, harga
FROM buku
ORDER BY harga DESC
LIMIT 3;
```

```sql
-- 3 books with the lowest stock
SELECT judul, stok
FROM buku
ORDER BY stok ASC
LIMIT 3;
```

:::warning
`LIMIT` without `ORDER BY` can't be relied on for "top N" — because row order without ORDER BY isn't guaranteed. Always combine both when you need a consistent "top N".
:::

## OFFSET: Skipping a Number of Rows

`OFFSET` is used together with `LIMIT` to skip a number of leading rows — useful for features like "page 2" of a list:

```sql
-- Skip the top 3 most expensive books, show the next 3 (ranks 4-6)
SELECT judul, harga
FROM buku
ORDER BY harga DESC
LIMIT 3 OFFSET 3;
```

## Anatomy of LIMIT

```sql
SELECT judul FROM buku ORDER BY harga DESC LIMIT 3;
```

The full clause order so far: `SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT ...`

## Summary

| Concept | Example |
|---------|---------|
| Limit row count | `LIMIT 5` |
| Top N | `ORDER BY harga DESC LIMIT 3` |
| Skip rows (paging) | `LIMIT 3 OFFSET 3` |
| Clause order | `SELECT...FROM...WHERE...ORDER BY...LIMIT...` |
