# SELECT and Choosing Columns

`SELECT` is the SQL statement you'll write most often. Its job is simple: **choose which columns to display** from a table.

## The Table We'll Use: `buku`

Throughout this unit we'll work with the `buku` (books) table in the `toko_buku` database, with these columns:

| Column | Type | Description |
|--------|------|-------------|
| `id` | INTEGER | Each book's unique number (primary key) |
| `judul` | TEXT | Book title |
| `penulis` | TEXT | Author name |
| `kategori` | TEXT | Book category (Fiction, Non-Fiction, etc.) |
| `harga` | INTEGER | Price in Rupiah |
| `stok` | INTEGER | Available stock |
| `tahun_terbit` | INTEGER | Year published |

## SELECT All Columns

The asterisk `*` means "all columns":

```sql
SELECT * FROM buku;
```

Output: all 12 rows, with all 7 columns above.

## SELECT Specific Columns

If you only need the title and price, name the columns, separated by commas:

```sql
SELECT judul, harga FROM buku;
```

Output:

```
judul                       | harga
-----------------------------+-------
Laskar Pelangi               | 68000
Bumi Manusia                 | 85000
Filosofi Teras                | 89000
...
```

The column order in the result **follows the order you wrote** in SELECT — not the original order in the table.

```sql
-- Order reversed from the original table, result is reversed too
SELECT harga, judul FROM buku;
```

:::note
`SELECT` never changes any data in the table — it only "reads" and displays it. Safe to experiment with freely!
:::

## Anatomy of a SELECT Query

```sql
SELECT judul, harga FROM buku;
```

- **`SELECT`** — the required keyword, signals "I want to retrieve data"
- **`judul, harga`** — the list of columns to display, comma-separated
- **`FROM buku`** — which table the data comes from
- **`;`** — the semicolon marks the end of the SQL statement

:::tip
The semicolon (`;`) at the end of a query matters, especially when you write more than one statement in a single playground. Get in the habit of always ending your queries with `;`.
:::

## Common Mistakes

**1. Forgetting the table name after FROM:**
```sql
SELECT judul, harga;  -- ERROR: doesn't know which table
```

**2. Misspelling a column name:**
```sql
SELECT juduls FROM buku;  -- ERROR: no such column: juduls
```

**3. Forgetting the comma between columns:**
```sql
SELECT judul harga FROM buku;  -- SQLite will mistake "harga" as an alias
```

## Summary

| Concept | Example |
|---------|---------|
| All columns | `SELECT * FROM buku;` |
| Specific columns | `SELECT judul, harga FROM buku;` |
| Column order | Follows the order written in SELECT |
| Statement end | Always close with `;` |

Next, we'll learn to **filter rows** with `WHERE` — so not all data shows up at once!
