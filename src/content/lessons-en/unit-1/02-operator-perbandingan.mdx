# Comparison Operators

Besides `=`, SQL has a full set of comparison operators usable in a `WHERE` clause — similar to the math operators you already know.

## List of Comparison Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| `=` | Equal to | `harga = 68000` |
| `<>` or `!=` | Not equal to | `kategori <> 'Fiksi'` |
| `>` | Greater than | `harga > 80000` |
| `<` | Less than | `stok < 5` |
| `>=` | Greater than or equal | `tahun_terbit >= 2010` |
| `<=` | Less than or equal | `harga <= 70000` |

## Usage Examples

Books published in 2010 or later:

```sql
SELECT judul, tahun_terbit
FROM buku
WHERE tahun_terbit >= 2010;
```

Books that are **not** in the Fiction category:

```sql
SELECT judul, kategori
FROM buku
WHERE kategori <> 'Fiksi';
```

Books with stock below 10 (might need restocking):

```sql
SELECT judul, stok
FROM buku
WHERE stok < 10;
```

:::tip
`<>` and `!=` mean exactly the same thing: "not equal to". SQLite supports both — pick one and use it consistently.
:::

## Comparison Operators on Text

`>` and `<` can also be used on text — compared alphabetically:

```sql
-- Book titles starting with a letter alphabetically after 'M'
SELECT judul FROM buku WHERE judul > 'M';
```

However, this is rarely used for free-form text — it's more common with numeric or date columns.

## Common Mistakes

**1. Using `=` for "greater than":**
```sql
WHERE harga = 80000;   -- only finds EXACTLY 80000
WHERE harga > 80000;   -- finds MORE THAN 80000 — different meaning!
```

**2. Flipped comparison direction:**
```sql
WHERE 80000 > harga;  -- valid, but reversed: means "price below 80000"
```

This is syntactically valid, but easier to read with the column on the left: `WHERE harga < 80000`.

## Summary

| Operator | Meaning |
|----------|---------|
| `=` | Equal to |
| `<>` / `!=` | Not equal to |
| `>`, `<` | Greater than / less than |
| `>=`, `<=` | Greater/less than or equal |
