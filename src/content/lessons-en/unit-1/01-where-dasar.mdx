# Filtering with WHERE

Without `WHERE`, `SELECT` always returns **every row** in the table. The `WHERE` clause lets you filter — only rows matching a given condition are shown.

## How WHERE is Evaluated

<img src="/images/where-filter-flow.svg" alt="WHERE filter flow: rows checked one by one" width="100%" />

SQLite checks **every row one at a time**: if the WHERE condition is true for that row, it makes it into the result. If not, that row is skipped.

## Filtering by a Number

```sql
SELECT judul, harga
FROM buku
WHERE harga > 80000;
```

Only books priced above 80000 show up.

## Filtering by Text

Text (string) values must be wrapped in single quotes `'...'`:

```sql
SELECT judul, kategori
FROM buku
WHERE kategori = 'Fiksi';
```

:::warning
Forgetting quotes around a text value is the most common mistake:
```sql
WHERE kategori = Fiksi;  -- ERROR: SQLite thinks Fiksi is a column name
```
Always use quotes: `WHERE kategori = 'Fiksi'`.
:::

## Filtering by Exact Equality

The `=` operator looks for an **exact match**:

```sql
SELECT * FROM buku WHERE penulis = 'Tere Liye';
```

If you misspell the case or add extra spaces, nothing will match (though SQLite's default text comparison is not case-sensitive for ASCII letters).

## Anatomy of WHERE

```sql
SELECT judul FROM buku WHERE harga > 80000;
```

- **`WHERE`** — starts the filtering condition
- **`harga > 80000`** — the condition expression: column, operator, comparison value
- A row is only shown if this expression evaluates to **true**

## Common Mistakes

**1. Placing WHERE before FROM:**
```sql
SELECT judul WHERE harga > 80000 FROM buku;  -- ERROR: wrong order
```
The correct order is always: `SELECT ... FROM ... WHERE ...`

**2. Forgetting quotes on text:**
```sql
WHERE judul = Sapiens;  -- ERROR
```

## Summary

| Concept | Example |
|---------|---------|
| Filter by number | `WHERE harga > 80000` |
| Filter by text | `WHERE kategori = 'Fiksi'` |
| Clause order | `SELECT ... FROM ... WHERE ...` |
| Text values | Always wrapped in single quotes `'...'` |
