# Joining Multiple Tables

The `perpustakaan` database has 3 tables, and the most useful questions usually need **all three at once**: "who borrowed what, and when?". We've touched on this briefly — now let's dig deeper.

## Joining Three Tables

```sql
SELECT anggota.nama, buku.judul, peminjaman.tanggal_pinjam, peminjaman.tanggal_kembali
FROM peminjaman
INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
INNER JOIN buku ON peminjaman.buku_id = buku.id;
```

Notice the structure: start with the "middle" table (`peminjaman`, which stores both Foreign Keys), then JOIN to `anggota`, then JOIN again to `buku`. Each `JOIN` clause adds one more table to the combined result so far.

## Evaluation Order: Left to Right

SQLite processes JOINs in sequence, top to bottom:
1. Start with `peminjaman`
2. Join with `anggota` → intermediate result: loans + member info
3. Join that intermediate result with `buku` → final result: loans + member info + book info

```sql
-- The table order in FROM/JOIN doesn't have to match the database's own order,
-- but must be logical: each JOIN needs a column from a table already joined so far
SELECT anggota.nama, buku.judul
FROM anggota
INNER JOIN peminjaman ON anggota.id = peminjaman.anggota_id
INNER JOIN buku ON peminjaman.buku_id = buku.id;
```

## Combining with WHERE, GROUP BY, ORDER BY

Once all tables are joined, every clause you've already mastered still works normally — as if the combined result were one big table:

```sql
-- How many times has each member borrowed a book?
SELECT anggota.nama, COUNT(*) AS jumlah_peminjaman
FROM peminjaman
INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
GROUP BY anggota.nama
ORDER BY jumlah_peminjaman DESC;
```

```sql
-- Titles borrowed by class 11B members, sorted by loan date
SELECT anggota.nama, buku.judul, peminjaman.tanggal_pinjam
FROM peminjaman
INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
INNER JOIN buku ON peminjaman.buku_id = buku.id
WHERE anggota.kelas = '11B'
ORDER BY peminjaman.tanggal_pinjam ASC;
```

:::tip
If your JOIN query starts feeling long, write one `JOIN` clause per line like the examples above — much easier to read than cramming everything onto one long line.
:::

## Summary

| Concept | Example |
|---------|---------|
| Join 3 tables | Two consecutive `INNER JOIN` clauses |
| Processing order | Left to right / top to bottom |
| JOIN + GROUP BY | Works normally, as if the combined result were one table |
