# INNER JOIN

`INNER JOIN` combines rows from two tables based on a related column — only rows with a **matching pair in both tables** appear in the result.

## Anatomy of an INNER JOIN

```sql
SELECT anggota.nama, peminjaman.tanggal_pinjam
FROM anggota
INNER JOIN peminjaman ON anggota.id = peminjaman.anggota_id;
```

- **`FROM anggota`** — the left table
- **`INNER JOIN peminjaman`** — the right table being joined
- **`ON anggota.id = peminjaman.anggota_id`** — the join condition: rows are considered "paired" if `id` in `anggota` equals `anggota_id` in `peminjaman`

The result now shows the borrower's **name**, not just a meaningless `anggota_id`.

## `table.column` Notation

Since two tables are joined, SQLite needs to know which column belongs to which table — especially if a column name is shared by both tables (like `id`). The `table_name.column_name` notation removes this ambiguity.

```sql
SELECT anggota.nama, buku.judul, peminjaman.tanggal_pinjam
FROM peminjaman
INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
INNER JOIN buku ON peminjaman.buku_id = buku.id;
```

This query joins **three tables at once** — we'll cover this in more detail in the Joining Multiple Tables lesson.

## INNER JOIN Only Takes Matches

If a member has never borrowed a book (like Gilang in our data), that member **won't appear** in the `INNER JOIN` result with `peminjaman` — because there's no matching `peminjaman` row for them.

## INNER JOIN with WHERE and ORDER BY

`WHERE` and `ORDER BY` still work as usual after a JOIN:

```sql
SELECT anggota.nama, buku.judul, peminjaman.tanggal_pinjam
FROM peminjaman
INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
INNER JOIN buku ON peminjaman.buku_id = buku.id
WHERE anggota.kelas = '10A'
ORDER BY peminjaman.tanggal_pinjam ASC;
```

:::note
The word `INNER` is actually optional — writing just `JOIN` (without `INNER`) in SQLite means exactly the same as `INNER JOIN`. But writing `INNER JOIN` explicitly makes your intent clearer compared to other JOIN types (`LEFT JOIN`, etc.).
:::

## Summary

| Concept | Example |
|---------|---------|
| INNER JOIN two tables | `FROM a INNER JOIN b ON a.id = b.a_id` |
| Explicit column notation | `table.column` |
| Only matched rows | Members without a loan don't appear |
| JOIN + WHERE + ORDER BY | Work as usual after a JOIN |
