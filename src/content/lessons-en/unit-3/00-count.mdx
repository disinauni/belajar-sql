# Counting Rows with COUNT

Every query we've written so far returns raw data **row by row**. But sometimes you just need one summary number — "how many books do we have?". This is where **aggregate functions** come in: functions that summarize many rows into a single value.

`COUNT` is the simplest aggregate function: it counts the number of rows.

## COUNT(*) — Counting All Rows

```sql
SELECT COUNT(*) FROM buku;
```

Output:
```
COUNT(*)
--------
12
```

Just one row, one number — totally different from `SELECT * FROM buku;`, which returns 12 rows of data.

## COUNT with WHERE

`COUNT(*)` can be combined with `WHERE` as usual — filter first, then count:

```sql
-- How many Fiction category books are there?
SELECT COUNT(*) FROM buku WHERE kategori = 'Fiksi';
```

## COUNT(column) vs COUNT(*)

`COUNT(column_name)` counts rows where that column is **not NULL**. Since the `buku` table has no NULL columns, `COUNT(*)` and `COUNT(judul)` produce the same number here — but if a column can be empty (like `email` in the earlier NULL lesson), the two can differ.

```sql
-- Same result on the buku table (no NULL columns there)
SELECT COUNT(*) FROM buku;
SELECT COUNT(judul) FROM buku;
```

## COUNT(DISTINCT column) — Counting Unique Values

```sql
-- How many DIFFERENT categories are there?
SELECT COUNT(DISTINCT kategori) FROM buku;
```

This counts the number of unique values, not the number of rows — similar to `SELECT DISTINCT kategori FROM buku;` but producing just the number directly.

## Aliasing the COUNT Result

```sql
SELECT COUNT(*) AS jumlah_buku FROM buku;
```

Without an alias, the result column's name shows up as `COUNT(*)` as-is — not very readable for other applications. Always give it a clear alias.

:::tip
`COUNT(*)` counts rows regardless of any column's contents — even if every column in a row is NULL, that row is still counted. This differs from `COUNT(column)`, which ignores NULL rows for that specific column.
:::

## Summary

| Function | Counts |
|----------|--------|
| `COUNT(*)` | All rows, regardless of column contents |
| `COUNT(column)` | Rows where that column isn't NULL |
| `COUNT(DISTINCT column)` | The number of unique values in that column |
