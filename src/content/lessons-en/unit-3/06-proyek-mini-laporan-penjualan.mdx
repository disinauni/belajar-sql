# Mini Project: Sales Report

Congratulations on reaching the end of Unit 3! You can now turn raw data into **summary reports** — exactly what a bookstore admin needs to make business decisions.

## The Toolkit You've Mastered

| Function/Clause | Use |
|-------------------|-----|
| `COUNT(*)` | Count the number of rows |
| `SUM(column)` | Add up values |
| `AVG(column)` | Compute an average |
| `MIN`/`MAX(column)` | Smallest/largest value |
| `GROUP BY` | Group rows to compute per group |
| `HAVING` | Filter group results by aggregate value |

## Case Study: Category Report

**"For each category, show the number of titles, total stock value, and average price — only categories with at least 2 titles, sorted by highest total stock value"**

```sql
SELECT
  kategori,
  COUNT(*) AS jumlah_judul,
  SUM(harga * stok) AS total_nilai_stok,
  ROUND(AVG(harga), 0) AS rata_rata_harga
FROM buku
GROUP BY kategori
HAVING COUNT(*) >= 2
ORDER BY total_nilai_stok DESC;
```

This single query answers a question that could take hours to work out manually in a spreadsheet.

## Reflection: What You've Mastered

| Concept | Function |
|---------|----------|
| `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` | Summarizing many rows into a single value |
| `GROUP BY` | Computing aggregates per group, not per whole table |
| `HAVING` | Filtering group results based on an aggregate value |
| F-W-G-H-O-L order | `FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT` |
