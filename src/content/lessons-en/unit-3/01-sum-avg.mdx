# SUM & AVG

After `COUNT`, the two most commonly used aggregate functions are `SUM` (adding up) and `AVG` (average). Both only work on **numeric** columns.

## SUM — Adding Up

```sql
-- Total stock across all books (in units, not Rupiah)
SELECT SUM(stok) FROM buku;
```

```sql
-- Total inventory value (price x stock, summed across all rows)
SELECT SUM(harga * stok) AS total_nilai_inventaris FROM buku;
```

## AVG — Average

```sql
SELECT AVG(harga) FROM buku;
```

The output will be a decimal number (e.g. `81416.666...`) since an average is rarely a whole number.

## Rounding with ROUND

The `ROUND(value, decimal_places)` function rounds a number for a cleaner display:

```sql
SELECT ROUND(AVG(harga), 0) AS rata_rata_harga FROM buku;
```

## SUM/AVG with WHERE

Just like `COUNT`, `SUM`/`AVG` can be combined with `WHERE` — filter first, then compute:

```sql
-- Average price of Fiction category books only
SELECT ROUND(AVG(harga), 0) AS rata_rata_fiksi
FROM buku
WHERE kategori = 'Fiksi';
```

:::note
`SUM` and `AVG` **automatically ignore NULL rows**. If there are 10 rows but 2 of them are NULL in the column being summed, `AVG` divides the total by 8 (not 10) — only rows with an actual value are counted.
:::

:::warning
`SUM`/`AVG` only make sense for numeric columns. `SUM(judul)` on a text column will produce an error or a meaningless value, depending on the RDBMS.
:::

## Summary

| Function | Use |
|----------|-----|
| `SUM(column)` | Adds up all values |
| `AVG(column)` | Computes the average |
| `ROUND(value, n)` | Rounds to n decimal places |
| NULL behavior | Ignored from the calculation |
