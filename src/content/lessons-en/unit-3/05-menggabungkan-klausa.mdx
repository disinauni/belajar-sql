# Combining All Clauses

You now know every major `SELECT` clause. Time to see the full writing order all at once — and understand SQLite's **evaluation** order underneath, which is actually different.

## Full Writing Order

```sql
SELECT column, AGGREGATE_FUNCTION(column) AS alias
FROM table
WHERE row_condition
GROUP BY grouping_column
HAVING aggregate_condition
ORDER BY column ASC/DESC
LIMIT n;
```

Every clause is optional except `SELECT` and `FROM` — but if used, the writing order above is **mandatory**.

## Logical Evaluation Order (Different from the Writing Order!)

<img src="/images/aggregate-functions.svg" alt="Summary of COUNT SUM AVG MIN MAX aggregate functions" width="100%" />

SQLite actually processes clauses in this **logical** order, from the inside out:

1. **FROM** — determine the source table
2. **WHERE** — filter raw rows
3. **GROUP BY** — group the remaining rows
4. **HAVING** — filter the group results
5. **SELECT** — choose/compute the displayed columns
6. **ORDER BY** — sort the final result
7. **LIMIT** — cap the number of final result rows

This explains why `WHERE` can't use `COUNT(*)` (not computed yet when `WHERE` runs) but `HAVING` can (computed after `GROUP BY`).

## Full Example

```sql
SELECT kategori, COUNT(*) AS jumlah, ROUND(AVG(harga), 0) AS rata_rata
FROM buku
WHERE stok > 0
GROUP BY kategori
HAVING COUNT(*) >= 2
ORDER BY rata_rata DESC
LIMIT 3;
```

Reading this query step by step:
1. Take all rows from `buku`
2. Filter to only `stok > 0`
3. Group by `kategori`
4. Compute `COUNT(*)` and `AVG(harga)` per group
5. Filter: only groups with a book count >= 2
6. Sort by highest average price
7. Take only the top 3

:::tip
If you're unsure which clause comes first, remember the acronym **F-W-G-H-O-L**: **F**ROM, **W**HERE, **G**ROUP BY, **H**AVING, **O**RDER BY, **L**IMIT.
:::

## Summary

| Clause | Function | Evaluated at step |
|--------|----------|---------------------|
| `FROM` | Source table | 1 |
| `WHERE` | Filter raw rows | 2 |
| `GROUP BY` | Group rows | 3 |
| `HAVING` | Filter group results | 4 |
| `SELECT` | Choose/compute columns | 5 |
| `ORDER BY` | Sort the result | 6 |
| `LIMIT` | Cap the row count | 7 |
