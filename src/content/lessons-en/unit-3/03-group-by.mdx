# Grouping with GROUP BY

In the previous lessons, aggregate functions always summarized the **entire table** into one number. But a more useful question is usually per group: "how many books **per category**?", not "how many books total?". `GROUP BY` makes this possible.

## Basic GROUP BY

```sql
SELECT kategori, COUNT(*) AS jumlah
FROM buku
GROUP BY kategori;
```

Output:
```
kategori           | jumlah
-------------------+-------
Fiksi              | 6
Non-Fiksi          | 1
Pengembangan Diri  | 2
Teknologi          | 2
Keuangan           | 1
```

<img src="/images/group-by-having.svg" alt="GROUP BY groups rows before aggregate functions are computed" width="100%" />

SQLite groups all rows sharing the same `kategori`, then runs `COUNT(*)` **per group** — not one number for the entire table.

## GROUP BY with Other Aggregate Functions

```sql
-- Average price per category
SELECT kategori, ROUND(AVG(harga), 0) AS rata_rata_harga
FROM buku
GROUP BY kategori;
```

```sql
-- Total stock value per category
SELECT kategori, SUM(harga * stok) AS total_nilai
FROM buku
GROUP BY kategori;
```

## Important Rule: SELECT Columns

When using `GROUP BY`, every column in `SELECT` must be one of:
1. A column present in `GROUP BY`, or
2. Wrapped in an aggregate function (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)

```sql
-- CORRECT-looking, but WRONG: kategori is in GROUP BY, judul is NOT — undefined/ambiguous
SELECT kategori, judul, COUNT(*) FROM buku GROUP BY kategori;  -- ⚠️ judul is ambiguous!
```

```sql
-- CORRECT: only kategori (in GROUP BY) and COUNT(*) (an aggregate function)
SELECT kategori, COUNT(*) FROM buku GROUP BY kategori;
```

:::warning
SQLite tends to be more permissive than PostgreSQL/MySQL about this rule — it may still run a query with an "ambiguous" column without erroring, but the result may pick an arbitrary row from each group. Don't rely on this behavior — always follow the rule above.
:::

## GROUP BY with Multiple Columns

```sql
-- Group by the combination of category AND publication year
SELECT kategori, tahun_terbit, COUNT(*) AS jumlah
FROM buku
GROUP BY kategori, tahun_terbit;
```

## GROUP BY with WHERE

`WHERE` filters rows **before** they're grouped:

```sql
-- Only books with stock > 0, grouped by category
SELECT kategori, COUNT(*) AS jumlah
FROM buku
WHERE stok > 0
GROUP BY kategori;
```

## Summary

| Concept | Example |
|---------|---------|
| Group + count | `SELECT kategori, COUNT(*) FROM buku GROUP BY kategori;` |
| Multiple grouping columns | `GROUP BY kategori, tahun_terbit` |
| Clause order | `SELECT ... FROM ... WHERE ... GROUP BY ...` |
| SELECT rule | Grouping column OR an aggregate function only |
