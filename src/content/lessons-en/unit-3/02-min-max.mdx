# MIN & MAX

`MIN` and `MAX` are aggregate functions for finding the smallest and largest values in a column.

## MIN & MAX on Numbers

```sql
SELECT MIN(harga) AS termurah, MAX(harga) AS termahal FROM buku;
```

A single query can produce two summary numbers at once — the cheapest and most expensive price.

```sql
SELECT MIN(tahun_terbit) AS tertua, MAX(tahun_terbit) AS terbaru FROM buku;
```

## MIN/MAX Aren't Just for Numbers

`MIN`/`MAX` also work on text columns (alphabetically) and dates (chronologically):

```sql
-- First and last title alphabetically
SELECT MIN(judul) AS judul_pertama_abjad, MAX(judul) AS judul_terakhir_abjad
FROM buku;
```

## Finding the Full Row for a MIN/MAX Value

`MIN(harga)` only returns **the number itself**, not the entire book row. To find out *which* book is the cheapest, complete with all its columns, combine `ORDER BY` + `LIMIT` (from Unit 1) — not `MIN()`:

```sql
-- Gets just the cheapest number
SELECT MIN(harga) FROM buku;

-- Gets the FULL row of the cheapest book
SELECT * FROM buku ORDER BY harga ASC LIMIT 1;
```

:::tip
This is a common beginner mistake: assuming `SELECT judul, MIN(harga) FROM buku` will show the cheapest book's title. That mixes a plain column with an aggregate function without `GROUP BY` — the result is not well-defined. We'll cover why in the next **GROUP BY** lesson.
:::

## MIN/MAX with WHERE

```sql
-- Most expensive price, Fiction category only
SELECT MAX(harga) AS termahal_fiksi FROM buku WHERE kategori = 'Fiksi';
```

## Summary

| Function | Use |
|----------|-----|
| `MIN(column)` | Smallest value (numbers) or alphabetically first (text/dates) |
| `MAX(column)` | Largest value (numbers) or alphabetically last (text/dates) |
| Full min/max row | Use `ORDER BY` + `LIMIT 1`, not `MIN()`/`MAX()` |

You now have 5 aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Next we'll learn **GROUP BY** — how to group rows so these aggregate functions can be computed per group, not just one number for the whole table.
