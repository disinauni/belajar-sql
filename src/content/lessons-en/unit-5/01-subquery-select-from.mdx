# Subqueries in SELECT & FROM

A subquery isn't limited to `WHERE` — it can also appear in `SELECT` (as an extra column) and in `FROM` (as a "table" produced by another query).

## Subquery in SELECT — Displaying a Comparison Value

```sql
SELECT
  judul,
  harga,
  (SELECT AVG(harga) FROM buku) AS rata_rata_semua
FROM buku;
```

Every result row now shows its own price **side by side** with the overall average — useful for comparison without running two separate queries.

```sql
-- Each book's price difference from the overall average
SELECT
  judul,
  harga,
  harga - (SELECT AVG(harga) FROM buku) AS selisih_dari_rata_rata
FROM buku;
```

:::note
A subquery in `SELECT` is conceptually run **once per result row** — though for a non-correlated subquery like this, SQLite is smart enough to compute it just once since the result never changes.
:::

## Subquery in FROM — Derived Table

You can use a query's result as a "temporary table" to query further:

```sql
SELECT kategori, rata_rata
FROM (
  SELECT kategori, AVG(harga) AS rata_rata
  FROM buku
  GROUP BY kategori
) AS ringkasan_kategori
WHERE rata_rata > 80000;
```

The query in parentheses produces a temporary table named `ringkasan_kategori` (via its alias), and the outer query `SELECT`s/`WHERE`s from that temporary table — just like an ordinary table.

:::tip
This pattern is useful when you need to filter based on a `GROUP BY` result in a more flexible way than `HAVING`, or when you want to further process an aggregate result (e.g. computing an aggregate of an aggregate).
:::

## Which One to Use When?

| Need | Put the Subquery in |
|------|------------------------|
| Filter rows by comparison | `WHERE` |
| Show a comparison value as a column | `SELECT` |
| Further process another query's result as a "table" | `FROM` |

## Summary

| Location | Use | Example |
|----------|-----|---------|
| `WHERE` | Filter rows | `WHERE harga > (SELECT AVG(harga) FROM buku)` |
| `SELECT` | Comparison value column | `(SELECT AVG(harga) FROM buku) AS rata_rata` |
| `FROM` | Derived table | `FROM (SELECT ... ) AS alias` |
