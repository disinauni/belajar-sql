# Subqueries in WHERE

Consider this question: **"which books are priced above the average price of ALL books?"**. You need two steps: (1) compute the average across all books, (2) compare each book against that number. A **subquery** lets you do both in **one** query.

## Basic Subquery in WHERE

```sql
SELECT judul, harga
FROM buku
WHERE harga > (SELECT AVG(harga) FROM buku);
```

<img src="/images/subquery-nesting.svg" alt="A subquery is evaluated first, its result used by the outer query" width="100%" />

The part `(SELECT AVG(harga) FROM buku)` is a **subquery** — a complete query written in parentheses, becoming part of the main query's (called the **outer query**) `WHERE` condition.

## Evaluation Order

SQLite evaluates the subquery **first**, then uses its result to evaluate the outer query:

1. Run `SELECT AVG(harga) FROM buku` → produces one number, e.g. `82916.67`
2. Substitute that number into the outer query: `WHERE harga > 82916.67`
3. Run the outer query with that now-"filled-in" condition

## Subquery vs Computing Manually

Without a subquery, you'd have to run two separate queries and copy the number manually:

```sql
-- Step 1: find out the average (say the result is 82916.67)
SELECT AVG(harga) FROM buku;

-- Step 2: manually copy that number into the second query
SELECT judul FROM buku WHERE harga > 82916.67;
```

A subquery combines both steps into a single query that's always accurate — if the data changes, the subquery automatically recomputes, unlike a manually copied number.

## Subqueries with Other Operators

A subquery that produces **a single value** (called a *scalar subquery*) can be used with any comparison operator:

```sql
-- The cheapest book (compare against the subquery's MIN result)
SELECT judul, harga FROM buku WHERE harga = (SELECT MIN(harga) FROM buku);
```

:::warning
A subquery used with `=`, `>`, `<`, etc. must return **exactly one row, one column**. If the subquery returns more than one row, SQLite will error. For subqueries returning many rows, use `IN` instead (covered in the next lesson).
:::

## Summary

| Concept | Example |
|---------|---------|
| Subquery in WHERE | `WHERE harga > (SELECT AVG(harga) FROM buku)` |
| Scalar subquery | A subquery producing one row, one column |
| Evaluation order | Subquery first, then the outer query |
