# IN with a Subquery

The subqueries in Unit 5 so far have always returned **a single value** (scalar). But a subquery can also return **many rows** — and `IN` is how you use one.

## Basic IN + Subquery

Remember the question from Unit 4: "which members have ever borrowed a book?" We already answered it with `JOIN`. Now let's answer it with a **subquery**:

```sql
SELECT nama
FROM anggota
WHERE id IN (SELECT anggota_id FROM peminjaman);
```

The subquery `(SELECT anggota_id FROM peminjaman)` produces a list of every `anggota_id` that has ever appeared in the loans table. `IN` then matches `id` in `anggota` against any value in that list.

## IN+Subquery vs JOIN — Two Ways, One Goal

```sql
-- Way 1: with JOIN (from Unit 4)
SELECT DISTINCT anggota.nama
FROM anggota
INNER JOIN peminjaman ON anggota.id = peminjaman.anggota_id;

-- Way 2: with IN + subquery
SELECT nama
FROM anggota
WHERE id IN (SELECT anggota_id FROM peminjaman);
```

Both produce the same list of names. `JOIN` is better suited when you need to display columns from **both tables** at once (e.g. member name AND book title). `IN` + subquery is more concise when you only need to filter one table based on its presence in another, without needing the second table's columns in the final result.

## NOT IN with a Subquery

```sql
-- Members who have NEVER borrowed (an alternative to LEFT JOIN + IS NULL)
SELECT nama
FROM anggota
WHERE id NOT IN (SELECT anggota_id FROM peminjaman);
```

:::warning
Remember the warning from Unit 2: `NOT IN` is dangerous if its subquery could produce `NULL`. Luckily, `peminjaman.anggota_id` in our schema is always `NOT NULL`, so it's safe here. But always stay alert — if a column inside a `NOT IN` subquery can be NULL, the result can unexpectedly come back empty. `NOT EXISTS` (next lesson) is a safer alternative.
:::

## IN + Subquery with an Extra Condition

The subquery itself can have its own `WHERE`:

```sql
-- Titles ever borrowed by class '10A' members
SELECT judul
FROM buku
WHERE id IN (
  SELECT peminjaman.buku_id
  FROM peminjaman
  INNER JOIN anggota ON peminjaman.anggota_id = anggota.id
  WHERE anggota.kelas = '10A'
);
```

## Summary

| Concept | Example |
|---------|---------|
| IN + subquery | `WHERE id IN (SELECT anggota_id FROM peminjaman)` |
| NOT IN + subquery | `WHERE id NOT IN (SELECT anggota_id FROM peminjaman)` |
| Alternative to | `JOIN` (when you don't need the second table's columns) |

Next: **EXISTS**, a safer and more efficient alternative to `IN`/`NOT IN` for checking data existence.
