# Handling NULL

The `buku` table we've used since Unit 1 happens to have no empty columns at all. But in the real world, unfilled data is common — e.g. a customer who hasn't provided an email yet. This lesson uses a new sample table: `pelanggan` (customers) `(id, nama, email)`.

| id | nama | email |
|----|------|-------|
| 1 | Dewi | dewi@email.com |
| 2 | Farhan | *(NULL)* |
| 3 | Citra | citra@email.com |
| 4 | Budi | *(NULL)* |
| 5 | Eka | eka@email.com |

## NULL Is Not Zero, Not an Empty String

`NULL` means **"no value at all"** — different from the number 0 or empty text `''`. Farhan and Budi haven't filled in their email; their email column isn't `""` or `"0"`, it's genuinely empty.

```sql
-- Logically WRONG — this will NEVER find NULL rows!
SELECT * FROM pelanggan WHERE email = NULL;
```

:::warning
`= NULL` **never evaluates to true**, even for a row whose email really is NULL! Ordinary comparison operators (`=`, `<>`) can't be used with NULL — SQL has dedicated operators: `IS NULL` and `IS NOT NULL`.
:::

## IS NULL & IS NOT NULL

```sql
-- Customers who HAVEN'T filled in their email
SELECT nama FROM pelanggan WHERE email IS NULL;
```

```sql
-- Customers who HAVE filled in their email
SELECT nama, email FROM pelanggan WHERE email IS NOT NULL;
```

## COALESCE — A Fallback Value for NULL

The `COALESCE()` function returns the first non-NULL value from its argument list — useful for displaying placeholder text:

```sql
SELECT nama, COALESCE(email, '(belum diisi)') AS email
FROM pelanggan;
```

Rows with a NULL email will show "(belum diisi)" ("not filled in yet"), while other rows still show their actual email.

:::tip
NULL is also "contagious" in calculations: `harga * NULL` results in NULL, not 0. If you sum a column containing NULL with `SUM()`, SQLite automatically ignores that NULL row (covered further in Unit 3).
:::

## Summary

| Concept | Example |
|---------|---------|
| Check empty | `WHERE email IS NULL` |
| Check filled | `WHERE email IS NOT NULL` |
| Fallback value | `COALESCE(email, '(belum diisi)')` |
| Common trap | `WHERE email = NULL` — **never works** |
