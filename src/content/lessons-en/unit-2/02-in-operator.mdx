# The IN Operator

Imagine you want books with category 'Fiksi', 'Non-Fiksi', **or** 'Teknologi'. With `OR` you'd have to repeat three conditions. `IN` shortens that into a single list.

## IN — Shorthand for a Chain of OR

```sql
-- Same as: kategori = 'Fiksi' OR kategori = 'Non-Fiksi' OR kategori = 'Teknologi'
SELECT judul, kategori
FROM buku
WHERE kategori IN ('Fiksi', 'Non-Fiksi', 'Teknologi');
```

Much more concise and readable than chaining repeated `OR`.

## NOT IN — The Opposite

```sql
-- All books EXCEPT Fiksi and Non-Fiksi categories
SELECT judul, kategori
FROM buku
WHERE kategori NOT IN ('Fiksi', 'Non-Fiksi');
```

## IN with Numbers

`IN` also works on numeric columns, not just text:

```sql
SELECT judul, tahun_terbit
FROM buku
WHERE tahun_terbit IN (2018, 2023);
```

:::tip
`IN` is most useful once the list has 3 or more values. For just 1-2 values, `WHERE x = a OR x = b` is still concise enough — pick whichever reads more clearly.
:::

:::warning
Be careful with `NOT IN` and `NULL` — if the list inside `NOT IN` contains a `NULL` value (e.g. from a subquery result in Unit 5), the entire `NOT IN` result can unexpectedly become empty. This is a well-known SQL pitfall we'll cover in more depth when we get to subqueries.
:::

## Summary

| Operator | Meaning | Example |
|----------|---------|---------|
| `IN (...)` | Matches any value in the list | `kategori IN ('Fiksi', 'Teknologi')` |
| `NOT IN (...)` | Matches none of the values in the list | `kategori NOT IN ('Fiksi')` |
