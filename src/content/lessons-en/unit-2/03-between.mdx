# The BETWEEN Operator

`BETWEEN` filters values that fall within a range — a more concise alternative to writing `>=` and `<=` conditions together.

## Basic BETWEEN

```sql
-- Same as: harga >= 60000 AND harga <= 90000
SELECT judul, harga
FROM buku
WHERE harga BETWEEN 60000 AND 90000;
```

## BETWEEN Is Inclusive

Both ends of the range are **included** in the result — a book priced at exactly 60000 or exactly 90000 still shows up.

```sql
SELECT judul, tahun_terbit
FROM buku
WHERE tahun_terbit BETWEEN 2004 AND 2011;
```

:::note
`BETWEEN 60000 AND 90000` should always be written with the **smaller value first, larger value second**. Reversing the order (`BETWEEN 90000 AND 60000`) won't cause an error, but always returns empty, since SQLite interprets it as `value >= 90000 AND value <= 60000`, which is impossible to satisfy.
:::

## NOT BETWEEN

```sql
-- Books priced OUTSIDE the 60000-90000 range
SELECT judul, harga
FROM buku
WHERE harga NOT BETWEEN 60000 AND 90000;
```

## BETWEEN vs Comparison Operators

`BETWEEN` is just syntactic sugar — the following two queries are identical:

```sql
SELECT judul FROM buku WHERE harga BETWEEN 60000 AND 90000;
SELECT judul FROM buku WHERE harga >= 60000 AND harga <= 90000;
```

Choose `BETWEEN` when the range is clear and singular — use manual `AND` when you need a more complex combination of conditions.

## Summary

| Concept | Example |
|---------|---------|
| Inclusive range | `harga BETWEEN 60000 AND 90000` |
| Inverse | `harga NOT BETWEEN 60000 AND 90000` |
| Equivalent to | `harga >= 60000 AND harga <= 90000` |
