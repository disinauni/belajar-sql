# Mini Project: Advanced Filters

Congratulations on reaching the end of Unit 2! You now have a full filtering toolkit: `AND`/`OR`/`NOT`, `LIKE`, `IN`, `BETWEEN`, and `IS NULL`. Let's combine them all to answer more realistic bookstore admin questions.

## Choosing the Right Operator

| Need | Operator |
|------|----------|
| Several conditions must all be true | `AND` |
| Any one of several conditions is enough | `OR` |
| Searching for a text pattern/fragment | `LIKE '%...%'` |
| Matches any value from a list | `IN (...)` |
| Value within a specific range | `BETWEEN ... AND ...` |
| Column empty/filled | `IS NULL` / `IS NOT NULL` |

## Case Study

**"Fiction or Non-Fiction books, priced between 60000 and 100000, whose title doesn't contain the word 'Cinta'"**

```sql
SELECT judul, kategori, harga
FROM buku
WHERE kategori IN ('Fiksi', 'Non-Fiksi')
  AND harga BETWEEN 60000 AND 100000
  AND judul NOT LIKE '%Cinta%';
```

Notice how `IN` replaces repeated `OR`, and `BETWEEN` replaces two `>=`/`<=` conditions, keeping the query concise even while combining many requirements.

## Unit 2 Summary

| Concept | Operator |
|---------|----------|
| Combined logic | `AND`, `OR`, `NOT` |
| Text patterns | `LIKE`, wildcards `%` `_` |
| Value lists | `IN`, `NOT IN` |
| Value ranges | `BETWEEN ... AND ...` |
| Empty values | `IS NULL`, `IS NOT NULL`, `COALESCE` |
