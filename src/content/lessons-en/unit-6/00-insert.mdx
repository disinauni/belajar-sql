# Adding Data with INSERT

Until now we've only **read** data with `SELECT`. Starting this unit, we learn to **change** data — beginning with `INSERT`, the statement for adding new rows.

:::note
Every `INSERT`/`UPDATE`/`DELETE` statement you try in this playground only changes the running database copy **in your own browser**. Click the **Reset** button any time to restore the data to its original state.
:::

## Basic INSERT

```sql
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit)
VALUES (13, 'Bumi', 'Tere Liye', 'Fiksi', 70000, 5, 2014);
```

- **`INSERT INTO buku`** — the target table
- **`(id, judul, penulis, kategori, harga, stok, tahun_terbit)`** — the list of columns to fill, in a specific order
- **`VALUES (...)`** — the corresponding values, in the **exact same** order as the column list

After running this, try `SELECT * FROM buku WHERE id = 13;` to see the new row.

## Why the Column List Matters

```sql
-- Risky: relies on the table's original column order, easy to get wrong if the schema changes
INSERT INTO buku VALUES (14, 'Rentang Waktu', 'Fiksi', 'Fiksi', 62000, 8, 2010);
```

:::warning
`INSERT` without an explicit column list assumes you know **exactly** the table's original column order — if the order is wrong (like the example above: `penulis` and `kategori` swapped), data goes into the wrong column **without any error**! Always write the column list explicitly, even if it's longer.
:::

## Adding Multiple Rows at Once

```sql
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit) VALUES
  (13, 'Bumi', 'Tere Liye', 'Fiksi', 70000, 5, 2014),
  (14, 'Bulan', 'Tere Liye', 'Fiksi', 72000, 3, 2015);
```

A single `INSERT` statement can add multiple rows by separating each parenthesized `(...)` group with a comma — much more efficient than writing `INSERT` repeatedly.

## INSERT and Primary Key

The `id` column in `buku` is a `PRIMARY KEY`, meaning its value must be **unique**. Trying to `INSERT` with an `id` that already exists produces an error:

```sql
-- ERROR: id 1 is already used by 'Laskar Pelangi'
INSERT INTO buku (id, judul, penulis, kategori, harga, stok, tahun_terbit)
VALUES (1, 'Judul Lain', 'Penulis Lain', 'Fiksi', 50000, 1, 2020);
```

## Summary

| Concept | Example |
|---------|---------|
| INSERT one row | `INSERT INTO buku (columns...) VALUES (values...);` |
| INSERT multiple rows | `VALUES (...), (...), (...);` |
| Safe practice | Always write an explicit column list |
| Primary Key constraint | `id` values must be unique, no duplicates |
