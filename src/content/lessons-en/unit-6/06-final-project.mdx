# Final Project: Design Your Own Database

Welcome to the closing project of the Learn SQL course! This lesson's playground is **completely empty** — you'll design a schema, fill in data, and analyze it entirely from scratch, combining **everything** you've learned from Unit 0 through Unit 6.

## Scenario: A School Store System

You've been asked to design a simple database for a school store, tracking **products** and **sales transactions**.

## Step 1: Design the Schema

```sql
CREATE TABLE produk (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL,
  harga INTEGER NOT NULL CHECK (harga >= 0),
  stok INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE transaksi (
  id INTEGER PRIMARY KEY,
  produk_id INTEGER NOT NULL REFERENCES produk(id),
  jumlah INTEGER NOT NULL CHECK (jumlah > 0),
  tanggal TEXT NOT NULL
);
```

Notice how this schema applies lessons from every unit: `PRIMARY KEY` and `FOREIGN KEY` (Unit 4), `NOT NULL`/`CHECK`/`DEFAULT` (Unit 6).

## Step 2: Fill in Initial Data

```sql
INSERT INTO produk (id, nama, harga, stok) VALUES
  (1, 'Pensil', 2500, 100),
  (2, 'Buku Tulis', 5000, 50),

  (1, 1, 5, '2026-06-01'),
  (2, 2, 2, '2026-06-01'),
  (3, 1, 3, '2026-06-02'),
  (4, 3, 10, '2026-06-02'),
  (5, 2, 1, '2026-06-03');
```

## Step 3: Analyze with JOIN, Aggregation, and Subqueries

```sql
-- Total revenue per product (JOIN + aggregation from Units 3 & 4)
SELECT produk.nama, SUM(produk.harga * transaksi.jumlah) AS total_pendapatan
FROM transaksi
INNER JOIN produk ON transaksi.produk_id = produk.id
GROUP BY produk.nama
ORDER BY total_pendapatan DESC;
```

```sql
-- Products that have never been sold (LEFT JOIN from Unit 4)
SELECT produk.nama
FROM produk
LEFT JOIN transaksi ON produk.id = transaksi.produk_id
WHERE transaksi.id IS NULL;
```
